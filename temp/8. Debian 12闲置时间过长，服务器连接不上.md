- **默认休眠机制**  
    Debian 12 默认启用了自动休眠（Idle Action），当系统长时间无操作时，可能进入休眠状态，导致网络服务中断。休眠后若唤醒机制异常，可能出现 HDMI 无输出的情况37。
    
- **休眠与唤醒机制失效**
    
    - **硬件兼容性**：某些主板的电源管理（如 USB/PCIe 节电功能）可能与 Linux 内核不兼容，导致休眠后无法唤醒1113。
        
    - **显卡驱动问题**：若使用独立显卡（如 NVIDIA），休眠后可能因驱动问题无法恢复显示输出11。

4. 考虑是休眠问题：
#### **1. 关闭系统自动休眠**

通过以下两种方式永久禁用休眠：

- **方法一：修改 `logind.conf`**
    
    bash
    
    复制
    
    sudo nano /etc/systemd/logind.conf
    # 修改以下参数
    IdleAction=ignore
    IdleActionSec=0
    # 保存后重启服务
    sudo systemctl restart systemd-logind
    
- **方法二：使用 `systemctl mask` 命令**
    
    bash
    
    复制
    
    sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target
    
    此方法直接禁用休眠相关的系统服务37。
