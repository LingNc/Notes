2. 你的 Debian 12 服务器在无人操作后断网的问题可能由多种原因导致。以下是详细的排查步骤和解决方案：

---

### 一、检查系统休眠/挂起配置
3. **禁用睡眠和休眠**  
   服务器通常不需要这些功能，检查并禁用：
   ```bash
   sudo systemctl mask sleep.target suspend.target hibernate.target hybrid-sleep.target
   ```

4. **检查 `systemd-logind` 配置**  
   修改 `/etc/systemd/logind.conf`：
   ```ini
   HandleSuspendKey=ignore
   HandleHibernateKey=ignore
   HandleLidSwitch=ignore
   IdleAction=ignore
   ```
   重启服务：
   ```bash
   sudo systemctl restart systemd-logind
   ```

---

### 二、网络相关排查
5. **检查网卡省电模式**  
   使用 `ethtool` 关闭节能模式（将 `enp0s3` 替换为你的网卡名称）：
   ```bash
   sudo ethtool -s enp0s3 wol d autoneg off
   sudo ethtool -s enp0s3 autoneg on  # 如果 autoneg 必须保持开启
   ```
   永久生效（创建 systemd 服务或添加到 `/etc/rc.local`）。

6. **内核日志分析**  
   在断网后（或重启后）检查日志：
   ```bash
   journalctl -k --since "24 hours ago" | grep -i 'error\|warn\|network\|eth0'
   dmesg | grep -i 'error\|network\|link'
   ```

7. **网络管理器行为**  
   如果使用 `NetworkManager`，检查配置：
   ```bash
   sudo nmcli con show <连接名称> | grep -i 'sleep\|autoconnect'
   ```
   修改配置为始终激活：
   ```bash
   sudo nmcli con mod <连接名称> connection.autoconnect yes
   ```

---

### 三、系统服务与超时设置
8. **检查 SSH 超时**  
   修改 `/etc/ssh/sshd_config` 防止 SSH 断开：
   ```ini
   ClientAliveInterval 300
   ClientAliveCountMax 3
   ```
   重启 SSH：
   ```bash
   sudo systemctl restart sshd
   ```

9. **防火墙和连接追踪**  
   检查防火墙规则是否丢弃空闲连接（尤其是 UDP 或无状态连接）：
   ```bash
   sudo iptables -L -n -v
   sudo nft list ruleset
   ```

---

### 四、硬件与驱动问题
10. **更新网卡驱动**  
   检查网卡型号和驱动：
   ```bash
   lspci | grep -i ethernet
   ethtool -i enp0s3
   ```
   访问 Debian 仓库或硬件厂商官网更新驱动。

11. **更换网线/端口测试**  
   排除物理层故障，尝试更换网线或路由器端口。

---

### 五、自动化恢复脚本（临时方案）
创建网络监控脚本 `/root/network_watchdog.sh`：
```bash
#!/bin/bash
ping -c 1 8.8.8.8 || {
    echo "Network down! Restarting network..."
    systemctl restart networking.service
    # 或 ifdown enp0s3 && ifup enp0s3
}
```
添加定时任务（每 5 分钟检测）：
```bash
sudo crontab -e
*/5 * * * * /root/network_watchdog.sh
```

---

### 六、高级调试手段
12. **记录网络状态历史**  
   使用 `vnstat` 监控流量：
   ```bash
   sudo apt install vnstat
   vnstat -l -i enp0s3
   ```

13. **抓包分析**  
   在后台运行 tcpdump：
   ```bash
   sudo tcpdump -i enp0s3 -w /tmp/network_debug.pcap
   ```
   断网后分析数据包是否异常。

---

### 七、关键问题聚焦
- **优先检查 `/var/log/syslog` 和 `journalctl -u systemd-networkd` 在断网时间点的记录**。
- **测试禁用所有节能选项后持续运行 `ping -i 60 8.8.8.8 > ping.log` 观察断开时间**。
- **如果虚拟机环境（如 VirtualBox），检查宿主机的虚拟网卡设置**。
