3. 配置页面功能说明
	1. General Setting中
		1. Enable Remote Desktop 启用远程桌面
		2. RDP port 远程桌面的端口
		3. Single session per user 限制每个用户单独一个会话
		4. Hide users on logon screen 在开始界面不显示多个用户切换
		5. Allow to start custom programs
	2. Authentication Mode
		1. 选择第三个 Network Level Authentication 才可以通过远程进行连接
