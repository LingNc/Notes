1. 备份 根据Ai：
	1. 在原系统或者LiveCD进行备份（如果可以进入）
	2. 在LiveCD系统中，先挂载要备份的系统目录到/mnt/root
		```bash
	sudo tar --exclude=proc --exclude=sys --exclude=dev --exclude=tmp --exclude=mnt --exclude=media -czpf /mnt/extra/rootfs.tar.gz -C /mnt/root .
		```
	1. 在原系统中/tmp 目录可以换成想要的任何目录
		```bash
		sudo tar --exclude=proc --exclude=sys --exclude=dev --exclude=tmp --exclude=mnt --exclude=media -czpf /tmp/rootfs.tar.gz -C / .
		```
2. 恢复操作：
3. 先将备份好的rootfs.tar.gz放在一个合适的地方
4. 使用一个任意Linux发行版live版本（有iso镜像即可），挂载为DVD即可，然后进入系统
5. 使用fdisk进行/dev/sda分区的初始化
6. 注意先创建一个EFI分区大概300MB来放引导（例如初始化为 /dev/sda1）初始化为 fat32
	```bash
	sudo mkfs.fat -F32 /dev/sda1
	```
7. 剩下的再建为主分区(/dev/sda2) 初始化为ext4
	```bash
	sudo mkfs.ext4 /dev/sda2
	```
8. 问题：要转移rootfs.tar.gz文件到hyperv虚拟机的话，我们可以采用在win 的 “计算机管理” 里面的磁盘管理，选择右边的更多操作的，创建VDHX文件，然后初始化为NTFS格式的磁盘，将rootfs转移到这个虚拟文件系统中，然后在hyperv中添加这个虚拟硬盘，然后mount即可使用。

10. 在Linux中挂载所需要的文件系统到 /mnt/root 进行后续的使用
	 ```bash
	# root
	sudo mkdir -p /mnt/root
	sudo mount /dev/sda2 /mnt/root
	# EFI
	sudo mkdir -p /mnt/root/boot/efi
	sudo mount /dev/sda1 /mnt/root/boot/efi
	```
11. 使用 `sudo tar -xpf /mnt/backup/rootfs.tar.gz -C /mnt/root`  进行还原
12. 更新系统配置fstab：
	1. 自动配置
	```bash
	sudo genfstab -U /mnt/root >> /mnt/root/etc/fstab  # 根据UUID生成挂载配置[2,9](@ref)
	```
	2. 如果没有这个软件可以采用手动更新fstab
	先手动获取sda启动盘的uuid
	```bash
	sudo blkid /dev/sda1
	sudo blkid /dev/sda2
	```
	编辑 `/mnt/target/etc/fstab`（如果存在该文件），将根分区和EIF分区的 UUID 更新为新分区的 UUID  
	 例如，将类似下面的那一行：  
     `UUID=旧UUID / ext4 defaults 0 1`     
  修改为：  
     `UUID=新获取的UUID / ext4 defaults 0 1`     
  保存退出
13. 安装GRUB引导
	1. 绑定目录
		sudo mount --bind /dev /mnt/root/dev   
		sudo mount --bind /proc /mnt/root/proc   
		sudo mount --bind /sys /mnt/root/sys
	2. 进入chroot环境
		sudo chroot /mnt/target /bin/bash
	3. 在 chroot 内安装 GRUB  
	 - 如果你的系统使用的是 Ubuntu/Debian 系统，运行：  
	  ```bash
		grub-install /dev/sda   
		update-grub
		```
	 - 对于其他发行版，命令可能略有不同（例如使用 `grub2-install` 和 `grub2-mkconfig`）
	4. 退出chroot `exit`
	5. 卸载绑定的目录
		```bash
		sudo umount /mnt/root/dev   
		sudo umount /mnt/root/proc   
		sudo umount /mnt/root/sys
		```
14. 卸载分区，并关闭LiveCD系统，然后弹出DVD驱动器
	`sudo umount /mnt/root`
