1. 手动下载配置，教程： https://blog.iswiftai.com/posts/clash-linux/
2. clash文件： 
	1. 这个好像不能使用tun模式![Clash-Linux-amd64-v1.14.0](clash-linux-amd64-v1.14.0.gz)
	2. 从clash for windows的linux版中提取出的clash,该版本可以使用tun模式 ![clash-linux](assert/clash-linux.bin)
3. 然后使用 `gunzip` 命令解压，并重命名为 `clash`
```bash
gunzip clash-linux-amd64-v1.14.0.gz
mv clash-linux-amd64-v1.14.0 clash
```
4. 下载 `Country.mmdb` 文件地址： https://github.com/Dreamacro/maxmind-geoip/releases
5. `Country.mmdb`: ![Country.mmdb](Country.mmdb)
6. 将`clash` 可执行文件赋值到 `/usr/local/bin/clash` 中
7. 在`etc/clash`创建文件夹,将`Country.mmdb`和`config.yaml`放进去
	1. 指令
		```bash
		sudo mkdir /etc/clash
		sudo cp clash /usr/local/bin
		sudo cp config.yaml /etc/clash/
		sudo cp Country.mmdb /etc/clash/
		```
	2. 创建 systemd 服务配置文件 `sudo vim /etc/systemd/system/clash.service`
		```bash
		[Unit]
		Description=Clash daemon, A rule-based proxy in Go.
		After=network.target
		
		[Service]
		Type=simple
		Restart=always
		CapabilityBoundingSet=CAP_NET_ADMIN CAP_NET_BIND_SERVICE CAP_NET_RAW
		AmbientCapabilities=CAP_NET_ADMIN CAP_NET_BIND_SERVICE CAP_NET_RAW
		ExecStart=/usr/local/bin/clash -d /etc/clash
		
		[Install]
		WantedBy=multi-user.target
		```
	3. `config.yaml`模板
	```yaml
	# 基础配置
	mixed-port: 12345
	authentication:
	  - "用户名1:密码1"
	  - "用户名2:密码2"
	allow-lan: true
	mode: Rule
	log-level: info
	external-controller: :9090
	# 供应商
	
	```
8. 使用快捷仓库clash-tun快速配置clash-tun模式： https://github.com/blue7wings/clash-tun (该仓库有点不太可用)
9. 快捷仓库2: https://github.com/nelvko/clash-for-linux-install?tab=readme-ov-file
