在Linux中使用 **`nmcli`**（NetworkManager命令行工具）可以方便地创建和管理 **macvlan** 虚拟网卡、配置IP地址以及持久化设置。以下是详细操作步骤：

---

## **一、使用 `nmcli` 管理 macvlan**

### **1. 创建 macvlan 连接**
#### **语法**
```bash
sudo nmcli connection add type macvlan \
    con-name <连接名称> \
    ifname <虚拟接口名称> \
    dev <物理网卡名称> \
    mode <模式> \
    ipv4.method <静态/自动> \
    ipv4.addresses <IP/掩码> \
    ipv4.gateway <网关>
```

#### **示例：静态IP**
```bash
# 创建名为 "macvlan-static" 的macvlan接口，基于eth0，模式为bridge，分配IP 10.85.11.43/24
sudo nmcli connection add type macvlan \
    con-name macvlan-static \
    ifname mvlan0 \
    dev eth0 \
    mode bridge \
    ipv4.method manual \
    ipv4.addresses 10.85.11.43/24 \
    ipv4.gateway 10.85.11.1
```

#### **示例：动态IP（DHCP）**
```bash
# 创建名为 "macvlan-dhcp" 的macvlan接口
sudo nmcli connection add type macvlan \
    con-name macvlan-dhcp \
    ifname mvlan1 \
    dev eth0 \
    mode bridge \
    ipv4.method auto
```

---

### **2. 启动/停止连接**
```bash
# 启动连接
sudo nmcli connection up macvlan-static

# 停止连接
sudo nmcli connection down macvlan-static
```

---

### **3. 查看连接信息**
```bash
# 查看所有连接状态
nmcli connection show

# 查看指定连接的详细配置
nmcli connection show macvlan-static

# 查看接口IP和状态
ip addr show mvlan0
```
## **三、持久化与配置文件**
通过 `nmcli` 修改的配置默认会保存到 **`/etc/NetworkManager/system-connections/`** 目录下的文件中，无需手动编辑文件。

---

## **四、macvlan 的高级配置**

### **1. 设置MTU**
为macvlan接口指定MTU（默认为物理网卡的MTX减底层协议开销）：
```bash
sudo nmcli connection modify macvlan-static ethernet.mtu 1500
```

## **五、删除连接**
```bash
# 永久删除连接
sudo nmcli connection delete macvlan-static
```

---

## **六、注意事项**
1. **混杂模式**  
   macvlan 需要物理网卡启用 `promiscuous mode`（一般无需手动设置，创建macvlan时会自动启用）。
2. **MAC地址冲突**  
   同一物理网卡下的macvlan接口需确保MAC地址不冲突。
3. **防火墙规则**  
   若使用防火墙（如 `firewalld` 或 `ufw`），需允许新接口的流量：
   ```bash
   sudo firewall-cmd --add-interface=mvlan0 --zone=public --permanent
   sudo firewall-cmd --reload
   ```

通过 `nmcli`，你可以高效管理macvlan、多IP绑定等配置，所有操作均支持持久化且无需重启系统！
