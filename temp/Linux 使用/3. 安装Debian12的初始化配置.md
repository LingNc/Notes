1. 设置为中文
	### **1. 编辑 `/etc/locale.gen` 文件**
	```bash
	sudo nano /etc/locale.gen
	```
	找到以下行（用 `Ctrl+W` 搜索 `zh_CN`），**取消注释**（删除行首的 `#`）：
	```ini
	zh_CN.UTF-8 UTF-8   # 简体中文
	```
	### **2. 生成语言环境**
	```bash
	sudo locale-gen
	```
	### **3. 手动设置默认语言**
	编辑 `/etc/default/locale`（不存在则新建）：
	```bash
	sudo nano /etc/default/locale
	```
	写入以下内容：
	```ini
	LANG=zh_CN.UTF-8
	LC_ALL=zh_CN.UTF-8
	```
	### **4. 立即生效**
	```bash
	source /etc/default/locale  # 当前会话生效
	```
	### **验证结果**
	```bash
	locale
	```
	输出应显示：
	```
	LANG=zh_CN.UTF-8
	LC_ALL=zh_CN.UTF-8
	...
	```
