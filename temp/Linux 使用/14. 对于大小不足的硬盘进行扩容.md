1. 创建日期：20250915
2. 测试环境：winserver + Debian12
3. 参考信息：Geimi 2.5 pro
4. 目前环境：只有10G的硬盘，其中有1G分给Swap分区，剩下的根目录分配 了约9G的空间，但是现在已经使用满了。
5. 具体操作：
	1. 在 Hyper-V 管理器中操作 (虚拟机需关机)
		1. **关闭 Linux 虚拟机**
		    - 在 Hyper-V 管理器中，右键点击你的 Linux 虚拟机，选择“关闭”。**不要**选择“关闭状态”，要确保操作系统完全关闭。
		2. **扩容主硬盘 (从 10GB 扩容)**
		    - 在 Hyper-V 管理器中，右键点击你的虚拟机，选择“设置”
		    - 在左侧导航栏中，找到你的主硬盘。它通常位于“SCSI 控制器”或“IDE 控制器”下，名为 `你的虚拟机名.vhdx`。
		    - 选中该硬盘，在右侧点击“编辑”按钮。
		    - 在“编辑虚拟硬盘向导”中，选择“扩展”。
		    - 输入你希望扩容到的**新总大小**。例如，如果你想增加 10GB，就输入 `20` GB。
		    - 完成向导。此时，你的主虚拟硬盘的总容量已经变大了，但 Linux 系统内部还不知道。
		3. **添加新的 4GB 硬盘用于 Swap**
		    - 同样在虚拟机的“设置”中，选中“SCSI 控制器”。
		    - 在右侧选择“硬盘驱动器”，然后点击“添加”。
		    - 选择“新建”来创建一个新的虚拟硬盘。
		    - 在“新建虚拟硬盘向导”中：
		        - **选择磁盘格式**：推荐 VHDX。
		        - **选择磁盘类型**：推荐“动态扩展”，它不会立即占用 4GB 物理空间。
		        - **指定名称和位置**：给它一个清晰的名字，例如 `Linux-Swap.vhdx`。
		        - **配置磁盘**：设置大小为 `4` GB。
		    - 完成向导。现在你的虚拟机已经连接了两个虚拟硬盘：一个扩容后的主硬盘和一个新的 4GB 硬盘。
		4. **启动虚拟机**
		    - 现在可以启动你的 Linux 虚拟机了。
	2. 在 Linux 客户机中配置新硬盘和扩容**
		接下来的所有操作都在 Linux 虚拟机的终端中完成。你需要使用 `sudo` 或者切换到 `root` 用户
		1. 识别磁盘
		首先，我们需要查看系统中的磁盘和分区情况。
		
		```
		lsblk
		```
		你应该会看到类似下面的输出：
		```
		NAME   MAJ:MIN RM  SIZE RO TYPE MOUNTPOINT
		sda      8:0    0   20G  0 disk
		├─sda1   8:1    0    9G  0 part /
		└─sda2   8:2    0    1G  0 part [SWAP]
		sdb      8:16   0    4G  0 disk
		```
		- `sda` 是你的主硬盘，现在大小应该是 `20G`。
		- `sda1` 是你的根分区 `/`。
		- `sda2` 是你**旧的** swap 分区。
		- `sdb` 是新添加的 `4G` 硬盘，它还没有任何分区。
		#### **2. 配置新的 4GB 硬盘作为 Swap 分区**
		我们将把 `/dev/sdb` 整个格式化为 swap 使用。
		```
		# 将 /dev/sdb 格式化为 swap 格式
		sudo mkswap /dev/sdb
		
		# 启用新的 swap 空间
		sudo swapon /dev/sdb
		
		# 验证新的 swap 是否已启用
		swapon --show
		```
		输出应该会显示 `/dev/sdb` 正在作为 swap 使用。
		#### **3. 永久挂载新 Swap (非常重要)**
		为了让系统重启后自动使用这个新的 swap，我们需要修改 `/etc/fstab` 文件。推荐使用 UUID 来挂载，这样更稳定。
		```
		# 获取新 swap 盘的 UUID
		sudo blkid /dev/sdb
		```
		你会得到一行输出，类似 `... UUID="xxxx-xxxx-xxxx-xxxx" TYPE="swap" ...`。复制这个 UUID。
		```
		# 编辑 fstab 文件
		sudo nano /etc/fstab
		```
		在文件末尾添加下面这一行，并将 `YOUR_UUID_HERE` 替换为你刚刚复制的 UUID：
		```
		UUID=YOUR_UUID_HERE none swap sw 0 0
		```
		保存并关闭文件 (在 nano 中是 `Ctrl+X`, `Y`, `Enter`)。
		#### **4. 停用并移除旧的 Swap 分区**
		现在新的 swap 已经工作了，我们可以安全地移除旧的了。
		```
		# 假设旧的 swap 是 /dev/sda2 (根据你的 lsblk 结果确认)
		sudo swapoff /dev/sda2
		
		# 再次编辑 /etc/fstab 文件
		sudo nano /etc/fstab
		```
		找到包含 `/dev/sda2` 的那一行，在行首加上 `#` 将其注释掉，或者直接删除。
		### **5. 扩容根分区**
		这是最关键的一步。我们现在有了两部分可用空间：
		- 主硬盘从 10G 扩容到 20G 后多出来的 `10G` 未分配空间。
		- 旧的 swap 分区 `/dev/sda2` 所在的 `1G` 空间。
		我们需要先删除旧的 swap 分区，然后将根分区 `/dev/sda1` 扩大以包含所有这些空间。
		**5.1. 使用 `fdisk` 删除旧分区并扩展主分区**
		```
		sudo fdisk /dev/sda
		```
		进入 fdisk 交互界面后，按顺序输入以下命令：
		1. 输入 `p`：打印分区表，记下 `/dev/sda1` 的起始扇区 (Start)。这**非常重要**。同时确认一下要删除的分区号，这里是 `2`。
		2. 输入 `d`：删除分区。
		3. 它会问你要删除的分区号，输入 `2`。
		4. 输入 `n`：新建分区。
		5. 输入 `p`：选择主分区。
		6. 分区号输入 `1`。
		7. **起始扇区 (First sector)**：输入你之前记下的 `/dev/sda1` 的起始扇区号。**必须完全一致！**
		8. **结束扇区 (Last sector)**：直接按回车，让它使用所有可用的剩余空间。
		9. 系统可能会提示分区包含某个文件系统签名，问你是否移除，输入 `N` (不移除)。
		10. 输入 `w`：将修改写入分区表并退出。
		**注意**：执行 `w` 之后，内核可能还在使用旧的分区表。你可能会看到需要重启的提示。**建议在此处重启系统**：`sudo reboot`。
		**5.2. 调整文件系统大小**
		重启后，分区本身已经扩大了，但文件系统还停留在旧的大小。我们需要让文件系统“填满”整个分区。
		首先，确认你的文件系统类型：
		```
		lsblk -f
		```
		查看 `/dev/sda1` 对应的 FSTYPE。
		- ** ext4 (最常见)**：
		    ```
		    sudo resize2fs /dev/sda1
		    ```
		#### **6. 最终验证**
		
		执行完以上所有步骤后，进行最后的检查。
		```
		# 检查磁盘空间和挂载点
		df -h
		
		# 检查 swap 空间
		swapon --show
		# 或者
		free -h
		```
		现在，`df -h` 的输出中，`/` 根目录的大小应该已经接近 20GB 了。而 `swapon --show` 或 `free -h` 应该只显示你新的 4GB swap (`/dev/sdb`)。
		至此，你已成功将主硬盘扩容，并将 swap 迁移到了一个独立的虚拟硬盘上。
