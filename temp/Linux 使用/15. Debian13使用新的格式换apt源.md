1. 创建日期：2025-9-19
2. 测试环境：Debian13
3. 参考教程：
	1. [Debian清华源](https://mirrors.tuna.tsinghua.edu.cn/help/debian/)
	2. [官方教程](https://wiki.debian.org/SourcesList)
4. /etc/apt/sources.list.d/debian.sources 为核心部分，新的格式(DEB822)，如果要使用清华源的情况下（Debian13）(不能放在原来的 /etc/apt/sources.list)
	```bash
	# 清华源的软件源，包含更新源
	Types: deb
	URIs: https://mirrors.tuna.tsinghua.edu.cn/debian
	Suites: trixie trixie-updates
	Components: main contrib non-free non-free-firmware
	Signed-By: /usr/share/keyrings/debian-archive-keyring.gpg
	
	# 安全更新源使用官方源
	Types: deb
	URIs: https://security.debian.org/debian-security
	Suites: trixie-security
	Components: main contrib non-free non-free-firmware
	Signed-By: /usr/share/keyrings/debian-archive-keyring.gpg
	```
	源码源（在没有需要的实话不必启用，因为会非常慢update）
	```bash
	Types: deb-src
	URIs: https://mirrors.tuna.tsinghua.edu.cn/debian
	Suites: trixie trixie-updates trixie-backports
	Components: main contrib non-free non-free-firmware
	Signed-By: /usr/share/keyrings/debian-archive-keyring.gpg
	```
1. 先备份 /etc/apt/sources.list.d/debian.sources 之后替换为上面的内容
2. 执行
```bash
sudo apt update
sudo apt upgrade
```
3. 问题：Debian Buster 以上版本默认支持 HTTPS 源。如果遇到无法拉取 HTTPS 源的情况，请先使用 HTTP 源并安装：
```bash
apt install apt-transport-https ca-certificates
```
