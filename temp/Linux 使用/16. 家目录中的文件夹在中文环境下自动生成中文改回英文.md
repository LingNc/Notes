1. 创建日期：2025-9-20
2. 测试环境：Debian13
3. 参考教程：[Geimi](Home中改英.ai.md)
4. 下载软件
```bash
sudo apt update
sudo apt install xdg-user-dirs
```
5. 切换为英文
```bash
LANG=en_US.UTF-8 xdg-user-dirs-update --force
```
6. 检测配置
```bash
cat ~/.config/user-dirs.dirs
```
7. 迁移文件
```shell
mv ~/桌面/* ~/Desktop/
mv ~/下载/* ~/Downloads/
mv ~/文档/* ~/Documents/
mv ~/音乐/* ~/Music/
mv ~/图片/* ~/Pictures/
mv ~/视频/* ~/Videos/
# 公共 和 模板 目录通常是空的，但以防万一
mv ~/公共/* ~/Public/
mv ~/模板/* ~/Templates/
```
7. 删除原始目录
```shell
rmdir ~/桌面
rmdir ~/下载
rmdir ~/文档
rmdir ~/音乐
rmdir ~/图片
rmdir ~/视频
rmdir ~/公共
rmdir ~/模板
```
8. 重新登录
