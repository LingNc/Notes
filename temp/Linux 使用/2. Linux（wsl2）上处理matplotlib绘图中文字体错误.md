2. 修改日期：20250718
3. 环境 WSL2 Debian12
4. 字体路径在 `/usr/share/fonts/` 中可以在这里创建一个文件夹 `fonts` 来保存一些自己下载的文字
5. 如果在指定字体名字的时候不知道字体的名字是什么，可以使用 
	```bash
	fc-scan /path/to/your/font.ttf
	```
	进行查看,如果觉得东西太多，进行过滤
	```bash
	fc-scan /path/to/your/font.ttf | grep 'family:'
	```
6. 最后在从其他地方把字体放在合适的位置之后应该刷新字体缓存
	1. 删除matplotlib字体缓存
	```bash
	rm -rf ~/.cache/matplotlib/*
	```
	2. 刷新系统字体缓存
	```bash
	fc-cache -fv
	```
	3. 并重启python程序或者juypter
7. 可以手动下载 noto cjk
	```bash
	sudo apt install fonts-noto-cjk  # Ubuntu/Debian
	```
8. 问题：在Python中plot使用
	```python
	# 设置中文显示
	plt.rcParams['font.sans-serif'] = ['Noto Sans CJK SC', 'SimHei']	
	plt.rcParams['axes.unicode_minus'] = False
	```
	进行设置依然无法显示中文，可以查看是否使用了seaborn库，配置了默认的一些风格
	比如：
	```python
	# 设置图表样式
	sns.set_style("whitegrid")
	plt.rcParams['figure.figsize'] = (12, 8)
	```
	他会覆盖之前的中文字体，所以需要把样式放前面，设置字体放后面
