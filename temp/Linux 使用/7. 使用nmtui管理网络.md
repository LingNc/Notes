1. 终端使用图形化配置网络，nmcli工具,或者nmtui是图形化工具可以配置网络
	1.  安装
		1. Debian/Ubuntu 
		```bash
		sudo apt install network-manager  # Debian/Ubuntu
		```
		2.  RHEL/CentOS
		```
		sudo yum install NetworkManager-tui  # RHEL/CentOS
		```
	2. 托管所有设备
		**检查当前网络设备状态**
		```bash
		nmcli device status
		```
		输出示例：
		```markdown
		DEVICE  TYPE      STATE      CONNECTION
		eth0    ethernet  connected  eth0
		wlan0   wifi      disconnected  --
		```
		- ​**STATE** 为 `unmanaged` 表示设备未被托管。
		**永久托管所有设备**
		修改 NetworkManager 配置文件 `/etc/NetworkManager/NetworkManager.conf`：
		```bash
		sudo nano /etc/NetworkManager/NetworkManager.conf
		```
		找到 `[keyfile]` 部分，确保以下配置存在：
		```ini
		[keyfile]
		unmanaged-devices=none
		```
		保存后重启 NetworkManager：
		```bash
		sudo systemctl restart NetworkManager
		```
		验证托管状态**
		```bash
		nmcli device show <设备名> | grep managed
		```
		输出示例：
		```markdown
		GENERAL.DEVICE:                         eth0
		GENERAL.MANAGED:                        yes
		```
		- 如果显示 `yes` 表示托管成功。
2. 基本使用操作
	以下是 **`nmcli`** 的**最常用命令总结**，涵盖网络连接管理、Wi-Fi、IP配置等场景，适合快速查阅：
	
	---
	
	### **1. 查看网络状态**
	| 命令 | 作用 |
	|------|------|
	| `nmcli` | 显示所有连接状态（简略） |
	| `nmcli connection show` | 列出所有连接（含名称、UUID、类型） |
	| `nmcli device status` | 查看物理设备状态（网卡、Wi-Fi等） |
	| `ip addr` | 查看所有接口的IP地址（更详细） |
	
	---
	
	### **2. 管理有线网络（以太网）**
	| 命令 | 作用 |
	|------|------|
	| `nmcli connection add type ethernet con-name my-eth ifname eth0` | 创建新以太网连接 |
	| `nmcli connection modify my-eth ipv4.method manual ipv4.addresses 192.168.1.100/24` | 设置静态IP |
	| `nmcli connection modify my-eth ipv4.method auto` | 改为DHCP自动获取IP |
	| `nmcli connection up my-eth` | 启用连接 |
	| `nmcli connection down my-eth` | 禁用连接 |
	| `nmcli connection delete my-eth` | 删除连接 |
	
	---
	
	### **3. 管理Wi-Fi网络**
	| 命令 | 作用 |
	|------|------|
	| `nmcli device wifi list` | 扫描可用Wi-Fi热点 |
	| `nmcli device wifi connect SSID password 密码` | 连接Wi-Fi（自动创建连接） |
	| `nmcli connection modify SSID wifi-sec.key-mgmt wpa-psk wifi-sec.psk 密码` | 修改已保存的Wi-Fi密码 |
	| `nmcli connection up SSID` | 重新连接已保存的Wi-Fi |
	| `nmcli radio wifi on/off` | 启用/禁用Wi-Fi硬件 |
	
	---
	
	### **4. 设置IP地址、DNS和网关**
	| 命令 | 作用 |
	|------|------|
	| `nmcli connection modify my-eth +ipv4.addresses 192.168.1.101/24` | 添加第二个IP地址 |
	| `nmcli connection modify my-eth ipv4.dns 8.8.8.8` | 设置静态DNS |
	| `nmcli connection modify my-eth +ipv4.dns 1.1.1.1` | 添加备用DNS |
	| `nmcli connection modify my-eth ipv4.gateway 192.168.1.1` | 设置默认网关 |
	| `nmcli connection modify my-eth ipv6.method ignore` | 禁用IPv6 |
	
	---
	
	### **5. 高级功能**
	| 命令 | 作用 |
	|------|------|
	| `nmcli connection add type vpn con-name my-vpn vpn-type openconnect` | 配置VPN连接 |
	| `nmcli connection add type bridge con-name br0 ifname br0` | 创建网桥 |
	| `nmcli connection add type macvlan con-name mvlan0 ifname mvlan0 dev eth0 mode bridge` | 创建macvlan虚拟网卡 |
	| `nmcli connection modify br0 bridge.stp no` | 禁用网桥的STP协议 |
	
	`nmcli connection modify` 仅修改配置文件，​**必须重新激活连接**才能生效：    
    ```bash
    sudo nmcli connection down macvlan0    # 先关闭
    sudo nmcli connection up maclan0      # 再启动
    ```
	---
	
	### **6. 故障排查**
	| 命令 | 作用 |
	|------|------|
	| `nmcli connection logs` | 查看NetworkManager日志 |
	| `journalctl -u NetworkManager` | 检查服务详细日志 |
	| `nmcli general reload` | 重载所有连接配置 |
	
	---
	
	### **常用场景示例**
	#### **场景1：快速连接Wi-Fi**
	```bash
	nmcli device wifi list                  # 查看可用Wi-Fi
	nmcli device wifi connect MyWiFi password 12345678
	```
	
	#### **场景2：临时切换静态IP**
	```bash
	nmcli connection modify eth0 ipv4.method manual ipv4.addresses 192.168.1.50/24
	nmcli connection up eth0
	```
	
	#### **场景3：创建网桥供虚拟机使用**
	```bash
	nmcli connection add type bridge con-name br0 ifname br0
	nmcli connection add type bridge-slave ifname eth0 master br0
	nmcli connection up br0
	```
	
	---
	
	### **注意事项**
	1. **修改配置后需激活**：  
	   ```bash
	   nmcli connection up <连接名>  # 使配置生效
	   ```
	2. **持久化存储**：  
	   所有`nmcli`命令修改的配置会自动保存到 `/etc/NetworkManager/system-connections/`。
	3. **权限问题**：  
	   大部分操作需要 `sudo`，但查看状态无需root权限。
