1. 安装
	```bash
	# Debian/Ubuntu
	sudo apt install x11vnc
	
	# CentOS/RHEL
	sudo yum install x11vnc
	
	# Arch Linux
	sudo pacman -S x11vnc
	```
2. 生成密码
	```bash
	x11vnc -storepasswd /path/to/passwordfile
	```
	修改密码文件权限
	```bash
	chmod 600 /path/to/passwordfile
	``` 
3. 命令行启动
	```bash
	x11vnc -display :0 -usepw -forever -shared -noxdamage -rfbport 5900
	```
	参数说明
	> - `-usepw` 选项用作通用密码标志
	> 	-  `-showrfbauth`、`-rfbauth` 和 `-storepasswd` 选项允许分别查看、使用或设置 RFB 的身份验证密码。
	> 	- `-passwdfile` 选项可用于提供 LibVNCServer 密码文件，该文件允许设置多个密码以及只读连接的密码。
	> - `-rfbport 5901`指定端口（默认 5900）
	> - `-shared` 允许多个客户端进行链接
	> - `-localhost` 仅允许本地链接
	> - `-bg` 后台运行
	> - `-display :0` 绑定屏幕
	> - `-forever` 保持服务运行
	> - `-noxdamage`：禁用 XDamage 扩展（兼容性模式）。
	> - `-geometry 1200x800` 分辨率
