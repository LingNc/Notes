4. 必要前提：
	1. 已经授予Termux root权限
	2. 管理root权限
		1. 直接使用 su 命令进入 root 权限，或者下载 tsu 或者 sudo 软件包。
			1. 下载tsu需要先下载root-repo：
				```bash
				pkg install root-repo
				pkg install tsu
				```
			2. 如果使用 sudo 需要安装：
			```bash
			pkg install sudo
			```
	3. 获取想要的系统的rootfs根目录
		1. 自己制作（Debian参考：[7. 制作arm64 Debian Rootfs文件系统](assert\7.%20制作arm64%20Debian%20Rootfs文件系统.md)）
		2. 下载官方或者社区提供的版本（对于Debian来说，proot-distro提供了一个精简的arm64的debian发行版rootfs，在[这里](https://github.com/termux/proot-distro/releases)可以找到）
			解压的时候以root身份解压（这种rootfs就是已经配置好的，不需要进行第二阶段的自举）
5. 对之前已经下载和解包好的rootfs进行进一步的配置，并且完全部署在目标机器上。
	1. 登入tsu进行挂载
		```bash
		# root环境
		tsu

		# Debian chroot 文件系统所在路径
		DEBIANPATH="/data/data/com.termux/files/home/debian-rootfs"

		# 执行挂载
		mount --bind /dev "${DEBIANPATH}/dev"
		mount -t devpts devpts "${DEBIANPATH}/dev/pts"
		mount -t proc proc "${DEBIANPATH}/proc"
		mount -t sysfs sysfs "${DEBIANPATH}/sys"
		```
	2. 登入chroot，应该使用env -i清空环境变量，否则无法登入
		验证是否能登录，环境是否正确，基本的命令能不能使用
		```bash
		env -i chroot $DEBIANPATH /bin/bash --login
		# 没有问题就退出 类似 bash-5.2#
		exit
		```
		![](Screenshot_2025-09-16-11-16-36-170_com.termux.jpg)
	3. 设置/data 分区挂载方式，启用setuid，防止权限问题
		```bash
		mount -o remount,dev,suid /data
		```
	4. 进行第二阶段的初始化（对于自制的来说，使用debootstrap的）
		```bash
		env -i chroot $DEBIANPATH /debootstrap/debootstrap --second-stage
		```
		![](Screenshot_2025-09-16-11-34-28-864_com.termux.jpg)
		如果程序意外终止，请先卸载之前挂载的四个路径，然后删除这个rootfs重新解压
		```bash
		# 1. 先尝试卸载所有可能的挂载点，否则会删掉/dev安卓上的路径（注意不要直接复制粘贴运行，因为只会检测到第一行在termux中，之前我就是这样删除了proc，sys直接崩溃了）
		umount "${DEBIANPATH}/dev/pts"
		umount "${DEBIANPATH}/sys"
		umount "${DEBIANPATH}/proc"
		umount "${DEBIANPATH}/dev"
		# 为了保证卸载完毕，退出termux并杀死后台，重新进入进行删除，并且进行检验 /dev 目录是个普通的文件夹，并非安卓的/dev，否则非常危险

		# 2. 彻底删除整个目录
		# 警告：请确认 DEBIANPATH 变量路径正确！
		echo "正在删除不完整的 rootfs: $DEBIANPATH"
		# 检测是否卸载干净
		mount | grep "$DEBIANPATH"
		# 如果上面有输出，说明还有挂载点没有卸载干净，请先卸载
		rm -r "$DEBIANPATH"

		# 3. 重新创建干净的空目录,然后重新解压
		mkdir "$DEBIANPATH"
		```
	5. 完成后登录
	```bash
	env -i chroot $DEBIANPATH /bin/su - root
	```
	显示 root@localhost:~#就说明正常了，测试ps，等验证proc和sys等挂载正确
	![](Screenshot_2025-09-16-12-31-08-246_com.termux.jpg)

	echo "nameserver 8.8.8.8" > /etc/resolv.conf
	echo "127.0.0.1 localhost" > /etc/hosts
