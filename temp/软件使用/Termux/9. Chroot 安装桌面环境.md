	2. 关闭kde的桌面特效（使用x11渲染的情况下，不关闭无法正常使用）

	```bash
	kwriteconfig5 --file kwinrc --group Compositing --key Enabled false
	```

		进入 桌面之后在KDE 桌面中进行设置设置自动启动的程序即可，因为要和kde桌面在同一个dbus会话中
		这是最简单、最标准的“KDE原生”方法。
	    1. 在您的 KDE 桌面中，打开“系统设置”(System Settings)。
        2. 在左侧的搜索框中，输入“自动启动”(Autostart)。
        3. 点击进入“自动启动”管理页面。
        4. 点击左下角的“添加...”按钮，然后选择“添加应用程序...”(Add Application...)。

9.  启动桌面环境进行测试（软件渲染）
	1. 配置启动前的设置全局环境变量
	设置 XDG_RUNTIME_DIR ，该环境变量在正常的 Linux 系统上由 systemd 自动设置，但当宿主系统为 Android 时，Linux 容器应该无法使用 systemd，故需手动设置。
	设置 DISPLAY （与Termux x11启动的编号要对应）。
	使用root创建并编辑 /etc/profile.d/XDG.sh 配置这两个环境变量，配置之后重新登录生效
    ```bash
	# 编辑 /etc/profile 或者 /etc/environment 或者 /etc/profile.d/kde-env.sh
	sudo vim /etc/profile.d/kde-env.sh # 此处是一个示例

	# ------ 写入以下内容 ------

	# 设置 XDG_RUNTIME_DIR 和 DISPLAY 环境变量
	export XDG_RUNTIME_DIR="/run/user/$(id -u)" # 这个环境变量必须写进chroot中，因为他不能从外边传入用户id
	export DISPLAY=":1"

	# 强制 X11（不要 Wayland）
    export XDG_SESSION_TYPE=x11
    export QT_QPA_PLATFORM=xcb
    ```
	重新登录生效
	2. 为用户创建运行时文件夹
	```bash
	sudo mkdir -p "$XDG_RUNTIME_DIR"
	sudo chown $USER:$USER "$XDG_RUNTIME_DIR"
	chmod 0700 "$XDG_RUNTIME_DIR"
	```
	3. 安装必要程序
	```bash
	sudo apt update
	sudo apt install xinit dbus-x11
	```
	4. 对plasma前置条件进行一些基本的配置
	先在Termux中启动 termux-x11，然后登入chroot启动plasma
	```bash
	export TMPDIR=$DEBIANPATH/tmp
	# 启动termux-x11
	termux-x11 :1 -ac &

	# 登录chroot
	su -c ./chroot-login.sh
	```
	修改/etc/init.d/dbus 脚本，注释掉对 /proc挂载点的检测，以便能够启动系统dbus
	```bash
	#  if ! mountpoint -q /proc/ ; then
	#    log_failure_msg "Can't start $DESC - /proc is not mounted"
	#    return
	#  fi
	```
	注释掉上面的这些部分，因为在chroot中没办法正确获得mount列表无法进行正确的检测

	(在termux-x11启动之后)修改/tmp/.X11-unit 和 /tmp/.ICE-unit的权限，将所属给root
	```bash
	sudo chown root:root /tmp/.X11-unix
	sudo chown root:root /tmp/.ICE-unix
	```
	启动媒体服务，KDE管理声音的
	```bash
	wireplumber &
	/usr/bin/pipewire &
	/usr/bin/pipewire-pulse &
	```
	启动系统的dbus deamon还需要一个文件夹
	```bash
	sudo mkdir -p /run/dbus
	```
	注意如果希望家目录中文件夹都是英文的，建议第一次进入使用en_US.UTF-8进入
	```bash
	# 可以选择修改系统语言
	sudo dpkg-reconfigure locales
	# 选择 en_US.UTF-8
	```
	5. 启动dbus和plasma
	```bash
	# 启动系统dbus
	sudo service dbus start
	# 启动会话dbus
	export $(dbus-launch)
	# 启动plasma_x11
	/etc/X11/Xssession
	```
	进入Termux X11查看桌面是否正常显示，显示成功即可

13. 建立新的启动脚本
    在使用桌面之后，之前的chroot-debian测试启动脚本不再好用，因为启动kde等进程之后，及时已经退出有些进程会在后台占用chroot文件夹中的一些自动，例如/dev,/proc,/sys等文件夹，导致无法正确退出挂载并且完全的退出系统，因为这些进程相当于还在安卓内核中运行着。
    1. 创建新的启动脚本（点击该链接打开[X11启动脚本](chroot-debian-x11.sh)）。
	2. 访问脚本，将脚本前面的配置参数部分按照自己的设置进行更改，例如chroot的路径，用户名等。
	3. 该脚本因为中间有个启动系统dbus deamon的过程，所以需要root权限运行。需在visudo中添加一行，配置免密码sudo启动dbus
	```bash
	visudo
	# 在visudo中添加
	用户名 ALL=(root) NOPASSWD: /usr/sbin/service dbus *
	```
	4. 将该脚本保存到~/.shortcuts/，就可以在桌面直接打开并且访问了
	![](assert/Screenshot_2025-09-20-21-57-45-183_com.termux.jpg)
