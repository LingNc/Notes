3. 环境：
	1. 小米平板6Max 骁龙8+gen1
	2. MIUI 14
	3. termux 118.3
4. 安装必要环境
	1. termux
	2. termux x11
		1. 安装x11-repo的仓库
		2. 安装termux-x11-nightly包
	3. 前置条件：要跑Debian手机需要至少4GB RAM，图形界面至少6GB。储存空间需准备10GB。
5. 使用 proot-distro 运行 Debian12 + 桌面环境
	1. 下载安装proot容器，音频服务器
	```bash
	pkg update
	pkg upgrade
	pkg install proot-distro pulseaudio vim
	```
	2. 安装Debian
	```bash
	proot-distro install debian
	```
	3. 登录 Debian
	```bash
	proot-distro login debian --user root
	```
	如图：![](Pasted%20image%2020250714003300.png)
	4. 更新并下载所需的软件
	```bash
	#更新
	apt update 
	apt install sudo vim firefox-esr
	```
6. 配置新的用户
	1. 修改root密码
	```bash
	passwd
	```
	2. 交互式创建新用户
	```shell
	adduser 用户名
	```
	3. 加入sudo用户组
	```bash
	visudo
	```
	进入vim之后编辑找到`root ALL=(ALL:ALL) ALL`那一行，在下一行加入以下内容：
	```bash
	user ALL=(ALL:ALL) ALL
	```
	4. 切换到普通用户
	```bash
	su 用户名
	cd
	```
7. 安装最小化桌面环境
	1. 安装kde桌面
	```bash
	apt install kde-plasma-desktop dbus-x11
	```
	大小比较大，有1G左右
	![](Pasted%20image%2020250714001259.png)
	2. 中间如果出现选择键盘布局，选择US
		![](Pasted%20image%2020250714004052.png)
