4. 制作rootfs
	1. 使用 `debootstrap` 制作
		`debootstrap` 是Debian官方的命令行工具，用于从零开始创建一个全新的Debian根文件系统。这是最“正宗”、最干净且可定制性最高的方法，但步骤也相对复杂。

		由于Termux官方源中没有`debootstrap`，您需要在一个已有的Linux环境中运行它来为我们的chroot创建文件系统。
	2. 准备一个临时的Linux环境：在Termux中使用`proot-distro`快速安装一个临时的Debian系统
	    ```
	    pkg install proot-distro
	    proot-distro install debian
	    ```
	3. 在Proot环境中安装`debootstrap`：
	    ```
	    # 登录到临时的proot环境
	    proot-distro login debian

	    # 在proot环境中安装debootstrap
	    apt update
	    apt install debootstrap -y
	    ```
	4. **运行`debootstrap`创建rootfs**： 在proot环境中，执行以下命令。这会在Termux的目录中创建一个全新的、干净的Debian 13 chroot文件系统。
	    - 首先，在Termux中为新的chroot创建一个目录（如果还没创建的话）： `mkdir ~/debian-chroot-manual`
	    - 然后，在**proot环境**中执行：
	    ```
	    # --arch=arm64 指定架构
	    # trixie 指定Debian 13版本代号
	    # $HOME/debian-chroot-manual 是目标目录在proot环境中的绝对路径，$HOME = /data/data/com.termux/files/home/(就是termux的家目录)
	    # http://deb.debian.org/debian 是软件包的下载源(官方)
	    # --foreign 表示只执行第一阶段，第二阶段需要在目标系统中完成（在termux中会有点问题，目前只进行第一阶段的下载和解包）
		# 完整命令
	   debootstrap --arch=arm64 trixie /data/data/com.termux/files/home/debian-chroot-manual http://deb.debian.org/debian --foreign
	    ```
	    这个过程会下载所有必要的基础包并配置一个最小系统，需要一些时间。（如下图）
	    ![](Pasted%20image%2020250915231130.png)

	5. **完成**： 命令成功结束后，`~/debian-chroot-manual` 目录就是一个可以直接使用的、干净的rootfs。但是并没有配置用户和密码等，后续还需要进入chroot进行一些基本设置见（[8. Termux Chroot环境创建](8.%20Termux%20Chroot环境创建.md)）。
