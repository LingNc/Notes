4. 制作rootfs
	1. 使用 `debootstrap` 制作
		`debootstrap` 是Debian官方的命令行工具，用于从零开始创建一个全新的Debian根文件系统。这是最“正宗”、最干净且可定制性最高的方法，但步骤也相对复杂。

		由于Termux官方源中没有`debootstrap`，您需要在一个已有的Linux环境中运行它来为我们的chroot创建文件系统。
	2. 在一个正常的Linux系统中进行配置
		1. 在Termux中使用`proot-distro`快速安装一个临时的Debian系统
			```
			pkg install proot-distro
			proot-distro install debian

			# 登录到临时的proot环境
			proot-distro login debian
			```
		1. 在proot-distro中配置出的权限不正确，也需要在proot中对其进行打包，然后在termux解包才可以正确处理。
	2. 在Linux环境环境中安装`debootstrap`：
	    ```
	    # 在proot环境中安装debootstrap
	    apt update
	    apt install debootstrap -y
	    ```
	3. **运行`debootstrap`创建rootfs**
	    - 首先，在系统中中为新的chroot创建一个目录（如果还没创建的话）： `mkdir ~/debian-chroot-manual`
	    - 然后，执行：
	    ```
	    # --arch=arm64 指定架构
	    # trixie 指定Debian 13版本代号
	    # $HOME/debian-chroot-manual 如果是目标目录在proot环境中的绝对路径，$HOME = /data/data/com.termux/files/home/(就是termux的家目录)，如果在Linux中就是直接~
	    # http://deb.debian.org/debian 是软件包的下载源(官方)
	    # --foreign 表示只执行第一阶段，第二阶段需要在目标系统中完成（因为不管proot还是正常的Linux可能架构或者其他的不同，目前只进行第一阶段的下载和解包）
		# 完整命令
	   debootstrap --arch=arm64 --foreign trixie /data/data/com.termux/files/home/debian-chroot-manual http://deb.debian.org/debian 
	    ```
	    这个过程会下载所有必要的基础包并配置一个最小系统，需要一些时间。（如下图）
	    ![](Pasted%20image%2020250915231130.png)

	4. **完成**： 命令成功结束后，`~/debian-chroot-manual` 目录就是一个干净的rootfs
	5. 将该文件夹打包为tar文件，然后传输到Termux中：
		```bash
		tar -cpzvf debian-chroot-manual.tar.gz -C ~/debian-chroot-manual .
		```
	在proot中（直接打包到家目录，然后使用tsu进行解压保留权限）：
	```bash
	sudo tar -cpzvf /data/data/com.termux/files/home/debian-chroot-manual.tar.gz -C /data/data/com.termux/files/home/debian-chroot-manual .
	```
	6. 在Termux中对于已经打包好的rootfs文件应该使用tsu（root权限）进行解压，因为解压时需要保留文件权限：
		```bash
		pkg install root-repo
		pkg install tsu
		tsu
		mkdir ~/debian-rootfs
		# 在proot中，刚刚创建的tar.gz就在当前目录下（保留权限解压）
		tar -xpzvf debian-chroot-manual.tar.gz -C ~/debian-rootfs
		```
	7. 完成：但是并没有完成第二阶段，还有配置用户和密码等，后续还需要进入chroot进行一些基本设置见（[8. Termux Chroot环境创建](8.%20Termux%20Chroot环境创建.md)）。
	8. 不想手动配置的话，在termux上proot-distro该github仓库制作的有对应的精简rootfs，从github下载或者使用proot-distro下载之后，按照上面的方法解压即可。
