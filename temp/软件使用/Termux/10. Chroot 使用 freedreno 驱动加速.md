1. 创建日期：2025-09-17
2. 测试环境：XiaomiPad6 Max(Soc 骁龙8+Gen1)，termux chroot debian 13 trixie(版本号)
3. 原理描述：
	**核心概念解析：为什么Freedreno比Zink快？**
	首先，理解我们要达成的目标至关重要。
	- **传统方式 (较慢的Zink):** 您的Linux应用（如KDE桌面）通过OpenGL图形接口发出绘图指令。在标准的Termux容器加速方案中，Mesa图形库里的**Zink**模块会将这些OpenGL指令“翻译”成Vulkan指令，然后交由**Turnip**驱动（Termux环境下的高通Vulkan驱动）去调用GPU。这个“翻译”过程会产生额外的性能开销，导致体验不够流畅。
	- **我们的目标 (更快的Freedreno + KGSL):** 我们的目标是绕过Zink翻译层。通过安装一个打了补丁的特殊版本Mesa，使其包含的**Freedreno**驱动能够直接与安卓系统底层的GPU内核驱动 (`/dev/kgsl-3d0`) 对话。这是一条更短、更直接的路径，能极大地提高GPU的利用效率，带来肉眼可见的流畅度提升。
	 **"xMeM patch"** 的方案，最初由开发者Lucas Fryzek编写了让Freedreno驱动适配安卓KGSL内核接口的代码，但它无法直接用于Termux:X11。**xMeM**将其移植并适配到了Termux:X11环境，后续由robertkirkman等人整合完善，最终使得这个高效方案成为可能。
4. 必要前提：
	1. 从Github安装Termux和Termux x11（不要从谷歌商店安装，避免Google Play商店版本的潜在问题。太老了）
	2. 基本环境运行成功，参考[9. Chroot 安装桌面环境](9.%20Chroot%20安装桌面环境.md)
5. 登录chroot容器中
```bash
su -c ./chroot-debian.sh
```
6. 下载驱动
```bash
wget https://github.com/lfdevs/mesa-for-android-container/releases/download/mesa-25.3.0-devel-20250725/mesa-for-android-container_25.3.0-devel-20250725_debian_arm64.tar.gz
```
7. 解压并安装
```bash
# 解压并覆盖安装
sudo tar -zxvf mesa-for-android-container_25.3.0-devel-20250725_debian_arm64.tar.gz -C /

# 刷新动态链接缓存
sudo ldconfig
```
8. 使用环境变量来启动桌面(X11)
```bash
ESA_LOADER_DRIVER_OVERRIDE=kgsl TU_DEBUG=noconform dbus-launch --exit-with-session /etc/X11/Xssession
```
或者将变量追加写入 /etc/profile.d/kde-env.sh（上个教程中创建的）
```bash
# 打开/etc/profile.d/kde-env.sh文件后写入
export ESA_LOADER_DRIVER_OVERRIDE=kgsl
export TU_DEBUG=noconform
```
或者使用快速启动脚本中，就有对应的环境变量操作
这样便可以使用freedreno加速
9. 对于不同的设备可能需要选择不同的mesa版本进行构建，我的骁龙 8+gen1可能不太适用 25.3
	使用24.3.0-rc2可以正确运行，并且没有那么多错误，vmark，glmark2
	参考这个（ https://github.com/droidvm/mesa-freedreno-patchs?tab=readme-ov-file ）
10. 进入桌面点击关于此系统查看驱动，不是llvmpipe就说明完成安装，可以感觉到比之前流畅多了
