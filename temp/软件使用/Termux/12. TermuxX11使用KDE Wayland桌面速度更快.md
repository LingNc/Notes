4. 必要前提：
	1. 已经完成chroot容器的建立（参考：[8. Termux Chroot环境创建](8.%20Termux%20Chroot环境创建.md)）
	2. 已经安装了桌面环境（参考：[9. Chroot 安装桌面环境](9.%20Chroot%20安装桌面环境.md)）这个里面是使用X11直接启动的，如果想用Wayland可以不使用X11忽略即可。
	3. 安装过Freedreno驱动，并且正常运行（参考：[10. Chroot 使用 freedreno 驱动加速](10.%20Chroot%20使用%20freedreno%20驱动加速.md)）
5. 设置容器内环境变量（可选，作为如果想在Termux起终端使用的话，否则之后会直接写在脚本中）
	```bash
	# 编辑 /etc/environment 文件
	sudo vim /etc/environment

	# 修改为以下内容
    export XDG_RUNTIME_DIR=/run/user/$(id -u) # 该变量必须写入chroot中，因为他不能从外边传入用户id
    export DISPLAY=:1

    export XDG_SESSION_TYPE=wayland
    export QT_QPA_PLATFORM=wayland
    # 这里应该没有变化
    export MESA_LOADER_DRIVER_OVERRIDE=kgsl
    export TU_DEBUG=noconform
	```
6. 编辑 ~/.config/kwinrc 文件，可选启用特效（在 Wayland 下，KWin 本身就是 compositor，特效自然跟着启用。）
7. 安装Wayland必须组件（正常情况下除了可选安装均已安装）
	在chroot Debian13容器内进行安装必要的软件包，获得Wayland支持（使用之前的简单登录脚本 debian-login.sh）（支持完整的wayland功能（Debian13已经包含在plasma-workspace包中了这个包应该已经安装过了），兼容X应用，qt软件能以最佳性能运行）这几个软件包应该都在kde-plasama-desktop安装的时候都安装过了
	```bash
	sudo apt update
	sudo apt install plasma-workspace xwayland qtwayland5
	```
	推荐安装(pipewire 和 xdg-desktop-portal-kde： 用于现代桌面功能，尤其是屏幕共享和截图 。很多现代应用（特别是浏览器）都需要这两个包才能在 Wayland 下正常进行屏幕录制或共享。wayland-utils:提供一系列 Wayland 的命令行工具，比如 wayland-info，可以用来查看当前合成器支持的 Wayland 协议，非常适合用于调试和验证 。)并且以上软件包经过验证在安装Debian13的时候包含在kde-plasama-desktop中了
	```bash
	sudo apt install pipewire xdg-desktop-portal-kde wayland-utils
	```
	可选安装（为了方便您后续按照指南进行自检，建议安装 Wayland 版本的性能测试工具：）
	```bash
	sudo apt install glmark2-wayland
	```
	装后，您就可以使用 glmark2-wayland 命令来测试 Wayland 会话下的 GPU 性能。
8. 由于Wayland的问题，现代Wayland依靠一些更复杂的依赖运行的，如果直接使用startplasma-wayland来启动，会遇到各种各样的问题，我们需要Wayland - X服务器的方法。新脚本将专门用于启动 Wayland 会话。它会先启动一个 KWin Wayland 合成器，**让它作为一个 X11 窗口运行**，然后再在这个合成器里启动 Plasma 的其他部分
