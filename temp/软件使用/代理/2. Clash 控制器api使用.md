1. 已经写好了一个脚本可以完成这些功能 ：![](clash-ctl.sh)
2. 使用方法：
	1. ​全新安装（自动装依赖）​​：
		```bash
		sudo ./clash-ctl.sh install
		```
		如果缺少curl/jq，会自动安装
	2. 显示帮助
		```bash
		clash-ctl help
		```
	3. 日常使用​：
		```bash
		clash-ctl set 127.0.0.1:9090
		clash-ctl groups
		clash-ctl switch Proxy "香港节点"
		```
	4. ​完全卸载​：
		```bash
		sudo clash-ctl uninstall
		```
		会提示是否删除配置文件
3. 在配置文件中可以看到控制器开放在那个端口，并且可以修改
	![](Pasted%20image%2020250605155139.png)
4. 发送请求验证控制器是否正常工作
	`/`:
	```bash
	curl -X GET http://127.0.0.1:9090
	```
	返回:
	```bash
	{"hello":"clash"}
	```
5. 常用操作
	### 2.1 获取所有代理信息

	```bash
	curl -X GET http://127.0.0.1:9090/proxies
	```

	返回所有代理组和节点的完整信息。

	### 2.2 获取特定代理组信息
	```bash
	curl -X GET http://127.0.0.1:9090/proxies/[代理组名称]
	```

	例如：

	```bash
	curl -X GET http://127.0.0.1:9090/proxies/Proxy
	```

	### 2.3 切换代理节点

	```bash
	curl -X PUT http://127.0.0.1:9090/proxies/[代理组名称] \
	-H "Content-Type: application/json" \
	-d '{"name": "[节点名称]"}'
	```

	示例：

	```bash
	curl -X PUT http://127.0.0.1:9090/proxies/Proxy \
	-H "Content-Type: application/json" \
	-d '{"name": "香港节点"}'
	```

	### 2.4 获取当前配置


	```bash
	curl -X GET http://127.0.0.1:9090/configs
	```

	### 2.5 更新配置


	```bash
	curl -X PUT http://127.0.0.1:9090/configs \
	-H "Content-Type: application/json" \
	-d '{"path": "/path/to/new/config.yaml"}'
	```

	### 2.6 获取规则

	```bash
	curl -X GET http://127.0.0.1:9090/rules
	```

	## 3. 带认证的请求

	如果 Clash 配置了 secret（在 config.yaml 中设置 `secret` 字段），需要在请求中添加认证头：

	```bash
	curl -X GET http://127.0.0.1:9090 \
	-H "Authorization: Bearer [你的secret]"
	```
