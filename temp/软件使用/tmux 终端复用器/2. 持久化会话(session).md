以下是如何 **持久化 tmux 会话** 的完整指南，包括 **会话保存/恢复、自动保存、跨窗口操作** 等高级技巧，适合进阶用户。

---

### 一、会话持久化核心问题
#### 1. **默认行为**
```bash
tmux new -s work  # 创建会话
exit              # 退出终端后会话消失
```

#### 2. **解决方法**
使用 [tmux-resurrect](https://github.com/tmux-plugins/tmux-resurrect) 插件实现会话持久化。

---

### 二、安装 tmux-resurrect 插件（推荐方案）
#### 1. 安装 tpm 插件管理器
```bash
git clone https://github.com/tmux-plugins/tpm ~/.tmux/plugins/tpm
```

#### 2. 配置 `~/.tmux.conf`
```bash
# 在 ~/.tmux.conf 最后添加
set -g @plugin 'tmux-plugins/tmux-resurrect'
set -g @plugin 'tmux-plugins/tmux-continuum'

# 自动保存会话（可选）
set -g @continuum-restore 'on'
set -g @continuum-save-interval '5'  # 每5分钟自动保存
```

#### 3. 加载配置并安装插件
```bash
tmux source-file ~/.tmux.conf
# 按 Ctrl+a I（大写 i） 安装插件
```

---

### 三、使用 tmux-resurrect 保存/恢复会话
#### 1. 保存会话（Ctrl+a 后按以下键）
```bash
Ctrl+a Ctrl+s  # 手动保存当前会话状态
```

#### 2. 恢复会话
```bash
tmux attach -t work  # 如果会话名存在则直接恢复
# 或重新启动 tmux
tmux
Ctrl+a Ctrl+r      # 强制恢复上次保存的会话
```

#### 3. 查看保存的会话文件
```bash
ls ~/.tmux/resurrect/
# 会生成类似 last 或 autosave 的会话文件
```

### 四、其他高级操作（提升效率）
#### 1. **动态调整面板布局**
```bash
Ctrl+a Alt+方向键  # 精确调整面板大小
Ctrl+a M-1         # 应用 "main-vertical" 布局（主右）
Ctrl+a M-2         # 应用 "main-horizontal" 布局（主下）
Ctrl+a M-3         # 左侧主区域，右侧上下分屏
Ctrl+a M-4         # 顶部主区域，下方全屏
Ctrl+a M-5         # 网格布局（自动均分）
```

#### 2. **同步多个面板输入**
```bash
Ctrl+a :setw synchronize-panes on  # 开启同步
Ctrl+a :setw synchronize-panes off # 关闭同步
```

#### 3. **跨窗口复制粘贴**
```bash
Ctrl+a [        # 进入复制模式
按空格键选择文本 → 回车复制
Ctrl+a ]        # 粘贴已复制内容
```

#### 4. **跨会话操作**
```bash
Ctrl+a :move-window -t 1  # 将当前窗口移动到会话 1
Ctrl+a :join-pane -t 0.1  # 将窗口 1 的面板加入当前窗口
```

### 五、剪贴板互通（tmux ↔ 系统）
#### 1. macOS 解决方案
```bash
brew install reattach-to-user-namespace

# 配置 ~/.tmux.conf
bind-key -T copy-mode-vi 'y' send -X copy-pipe-and-cancel 'reattach-to-user-namespace pbcopy'
bind-key p run "reattach-to-user-namespace pbpaste | tmux load-buffer - && tmux paste-buffer"
```

#### 2. Linux 解决方案
```bash
sudo apt install xclip

# 配置 ~/.tmux.conf
bind-key -T copy-mode-vi 'y' send -X copy-pipe-and-cancel 'xclip -selection clipboard'
bind-key p run "xclip -o | tmux load-buffer - && tmux paste-buffer"
```

### 六、自动化脚本与模板（Tmuxinator）
#### 1. 安装 Tmuxinator
```bash
gem install tmuxinator
```

#### 2. 创建项目模板 `~/.tmuxinator/work.yml`
```yaml
name: work
root: ~/workspace

windows:
  - editor:
      layout: main-vertical
      panes:
        - vim
        - server: python3 app.py
  - logs: tail -f /var/log/app.log
```

#### 3. 启动项目
```bash
tmuxinator start work
```

### 七、常见问题排查
#### 1. **会话无法恢复**
```bash
# 检查保存的会话文件是否存在
ls ~/.tmux/resurrect/
# 如果文件缺失，说明未正确保存
```

#### 2. **插件未生效**
```bash
# 重新加载配置并安装插件
tmux source-file ~/.tmux.conf
Ctrl+a I  # 重新安装插件
```

#### 3. **路径冲突**
```bash
# 确保 tmux 插件路径正确
echo $PATH | grep ~/.tmux/plugins
```

### 九、进阶技巧
#### 1. 自定义状态栏（显示时间/CPU）
```bash
# 在 ~/.tmux.conf 中添加
set -g status-right '#[fg=blue]CPU:#{cpu_percentage} | #[fg=green]%Y-%m-%d %H:%M'
```

#### 2. 快捷键绑定（如保存会话）
```bash
# 在 ~/.tmux.conf 中添加
bind-key S run "tmux save-buffer ~/.tmux/resurrect/last; echo 'Session saved'"
```

#### 3. 使用 `tmux-continuum` 实现自动保存
```bash
set -g @continuum-restore 'on'
set -g @continuum-save-interval '5'  # 每5分钟自动保存
```
