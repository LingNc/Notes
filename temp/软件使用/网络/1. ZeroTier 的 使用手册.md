	5. 特殊选项
	- -q `zerotier-cli`
		```shell
		使用方法：zerotier-one_x64.exe [选项] <命令/路径> [<参数>]  
		
		可用选项：  
		  -h                      显示本帮助信息  
		  -v                      显示版本信息  
		  -j                      显示完整原始JSON格式输出  
		  -D<路径>               指定ZeroTier主目录路径（用于自动检测参数）  
		  -p<端口>               设置HTTP端口（默认：自动）  
		  -T<令牌>               指定认证令牌（默认：自动）  
		
		可用命令：  
		  info                    显示状态信息  
		  listpeers               列出所有对等节点（原始格式）  
		  peers                   列出所有对等节点（美化格式）  
		  listnetworks            列出所有网络  
		  join <网络ID>           加入指定网络  
		  leave <网络ID>          离开指定网络  
		  set <网络ID> <设置项>   配置网络参数  
		  get <网络ID> <设置项>   获取网络参数  
		  listmoons               列出所有Moon节点（联邦根服务器集）  
		  orbit <世界ID> <种子>   通过任意根节点加入Moon网络  
		  deorbit <世界ID>       离开Moon网络  
		  dump                    导出调试信息（用于技术支持）  
		
		可用设置项：  
		  可与[get/set]命令配合使用的设置项包括：  
		  - 从"zerotier-cli -j listnetworks"命令JSON输出中获取的属性名称  
		  - 特殊快捷参数：ip, ip4, ip6, ip6plane, ip6prefix  
		  例如：  
		  zerotier-cli get <网络ID> ip6plane  
		  将返回分配给本节点的6PLANE地址  
		
		注：  
		1. 使用网络管理命令需确保服务已运行  
		2. Moon节点操作需先获取世界ID和至少一个种子节点地址  
		3. 带"-j"选项时输出适合程序解析，不带时输出人类可读格式
		```
	- -i `zerotier-idtool`
		```shell
		使用方法：-i <命令> [<参数>]  
		
		命令列表：  
		  generate [<identity.secret>] [<identity.public>] [<自定义前缀>]  
		    生成新的ZeroTier身份密钥对（可指定输出文件和自定义地址前缀）  
		
		  validate <identity.secret/public>  
		    验证身份密钥文件的合法性  
		
		  getpublic <identity.secret>  
		    从私钥文件导出对应的公钥  
		
		  sign <identity.secret> <文件>  
		    使用私钥对文件进行数字签名  
		
		  verify <identity.secret/public> <文件> <签名>  
		    验证文件签名的有效性  
		
		  initmoon <首个种子节点的identity.public>  
		    初始化Moon服务器配置（需提供种子节点公钥）  
		
		  genmoon <moon.json配置文件>  
		    根据JSON配置生成Moon服务器部署文件  
		
		示例用法：  
		1. 生成新身份：  
		   zerotier-idtool -i generate my.secret my.public  
		
		2. 创建Moon配置：  
		   zerotier-idtool -i initmoon seed.public > moon.json  
		   zerotier-idtool -i genmoon moon.json > 000000deadbeef00.moon  
		
		注：  
		• 所有文件路径建议使用绝对路径  
		• 生成Moon配置需先准备至少一个种子节点  
		• 签名验证功能可用于安全通信验证
		```
