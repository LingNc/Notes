1. 创建日期： 20250818
2. 测试环境： win11
3. 先创建 vhdx 交换文件并指定最大大小
4. 创建为动态文件
	1. 在专业版win中，安装过hyper-V组件之后可以使用以下命令创建
	```powershell
	New-VHD -Path "D:\WSL\swap.vhdx" -SizeBytes 16GB -Dynamic
	```
	2. 在家庭版win中
		```powershell
		diskpart
		```
		```powershell
		create vdisk file="D:\WSL\swap.vhdx" maximum=16384 type=expandable
		```
		- `maximum=16384` 表示 16GB（单位 MB）。
		- `type=expandable` 表示动态扩展（类似 `-Dynamic`）。
5. 在右下角中搜索程序 wsl setting 找到内存和处理器选项卡
6. ![](Pasted%20image%2020250818230108.png)然后输入交换文件大小并指定交换文件的位置（就是刚才那个swap.vhdx文件的路径）
