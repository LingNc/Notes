4. 首先使用计算机管理或者hyperv的磁盘管理，创建虚拟硬盘文件并设置一些基本的属性
	1. 设置磁盘类型是vdhx还是其他的类型
	2. 设置大小和位置
5. 然后使用wsl.exe进行挂载，测试
	1. 操作
	```powershell
	wsl --mount --vhd "C:\path\to\your\disk.vhdx" --name <发行版名称>
	```
	2. 取消挂载（当wsl关机的时候会自动取消挂载）
	```powershell
	wsl --shutdown
	```
	3. 可以在这个时候对这个磁盘进行一些分区或者之后再做
6. 配置自动挂载 配置win计划任务在登录时(我的配置好的任务导出xml:[自动附加任务模板](自动附加vhdx到ml-python.xml))
	1. 或者在计划任务中的触发器是![](Pasted%20image%2020250724160759.png)
	2. 日志名称: Microsoft-Windows-Hyper-V-Compute-Operational 来源:  Microsoft-Windows-Hyper-V-Compute ，事件ID是2014表示hyperv的虚拟机启动的日志
	3. 配置触发器为上面的事件发生时触发![](Pasted%20image%2020250724162642.png)
	4. 配置任务为，一个ps1脚本，用来挂载对应的硬盘(如[自动挂载脚本](assert\auto_mount.ps1))
		```powershell
		wsl --mount --vhd "C:\path\to\your\disk.vhdx" --name <发行版名称>
		```
	5. 注意回到主界面，给这个任务起一个名字，并且勾选以最高权限运行（因为wsl的挂载需要管理员权限）![](Pasted%20image%2020250724162833.png)
7. 配置linux中自动挂载指定UUID的分区到某个文件目录中
	1. 挂载之后，进行初始化分区和ext4的格式化，使用的fdisk和lsblk查看
	2. 然后记录一下你的分区的UUID，修改 /etc/fstab 中添加一行
	```ini
	UUID=2a954ac9-bbb8-45bb-a2db-06a3beaee70b /path/to/your ext4 defaults 0 
	```
	3. 然后重启发行版，下次即可自动挂载
