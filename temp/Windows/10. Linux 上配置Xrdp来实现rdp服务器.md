3. 配置KDE会话

为了使XRDP能够正确加载KDE桌面，需要创建一个启动脚本。在用户主目录下创建`.xsession`文件，并添加以下内容：


```Bash
echo "startplasma-x11" > ~/.xsession chmod +x ~/.xsession
```


这将确保XRDP使用KDE Plasma作为默认桌面环境。

### 4. 调整权限（如需）

确保`.xsession`文件的权限设置正确，以便XRDP可以访问它：
```Bash
chown <用户名>:<用户组> ~/.xsession
```

### 5. 重启XRDP服务

完成上述配置后，重启XRDP服务以应用更改：

```Bash
sudo systemctl restart xrdp
```
