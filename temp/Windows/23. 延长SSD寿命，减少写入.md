3. 以下方法都是针对SSD的而不是HDD，大部分方法对HDD不适用并且会降低HDD的性能
4. 一些方法：
	1. ram disk：使用ram内存作为一个虚拟硬盘，将一些只会在开启软件之后使用的临时缓存，或者暂时下载的并且解压的东西存放，减少对SSD的写入
	2. 禁用休眠（非笔记本）：不生成 hiberfil.sys 文件并且不会频繁写入休眠文件到C盘
		```cmd
		powercfg /h off
		```
	3. 启用TRIM（默认固态都是开启的），和碎片整理：
		在win中随便整理会被win自动识别为一个“重新裁剪”，可以通过在设置->优化驱动器->碎片整理 开启定期优化，重新裁剪是针对SSD的一种特殊的优化，可以增加SSD的访问速度，延长寿命。（但是 碎片整理不适合SSD只适合HDD）
	4. 调整pagefile.sys 页面文件到其他盘，或者在内存足够大的时候禁用这个功能。
	5. 禁用superfetch，一种预加载一些用户可能会使用的东西进入内存，影响不是很大，在现代 win10/11系统中只需要关闭和禁用SysMain.sys
		```powershell
		sc stop "SysMain" & sc config "SysMain" start= disabled
		```
	6. PrimoCache软件，可以在非系统盘，并且并不重要的盘，比如游戏盘，某些软件盘，使用，通过将一部分的ram或者SSD作为一个高速缓存区（这里使用ram）可以大幅提高读写速度（等同RAM），并启用延迟写入，在这一段时间内的东西并不会被立刻同步到硬盘，而是在一段时候会将这一段时间内频繁的操作合并为一个写入硬盘，可以减少对SSD的损耗（有限）。该软件更多的是可以通过这种手段提升HDD的速度。
5. 软件设置
	1. 通过调整一些有这频繁读写硬盘的软件的缓存路径来减少对SDD的损耗
	2. 常用的高读写的软件
