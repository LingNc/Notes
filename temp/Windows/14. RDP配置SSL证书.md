1. 教程： https://blog.hoshiroko.com/archives/b2ebf38631d9/
2. 下载证书 为文件,例如 ，证书： `lingnc.crt`，私钥： `ingnc.key`，或者证书: fullchain.pem 私钥: privkey.pem，或者 证书myssl.pem 私钥myssl.key
3. 转换证书 
	```powershell
	openssl pkcs12 -export -in [证书路径] -inkey [私钥路径] -out [output.pfx 输出文件路径]
	```
	1. 会提示输入一个密码，来确保证书的安全
4. 添加证书：
	1. 直接双击证书导入向导
	2. 存储位置选”本地计算机”
	3. 导入文件，它已经给我选好了，直接下一步
	4. 输入密码，这密码是你下载证书压缩包里附带的密码，或者是你转换时输入的那两遍密码
	5. 证书存储位置选”个人”
	6. 点完成，即可导入成功
5. 这时我们打开`Win+R`输入`certlm.msc`找到 个人→证书 就能看到我们添加的证书了  
6. 授权
	选定刚添加的证书右键 所有任务→管理私钥 在 用户→添加→高级→立即查找 在搜索结果里找到`NETWORK SERVICE`双击添加确定即可  
	在用户里找到我们刚才添加的`NETWORK SERVICE`选定后权限设置为可读取，设置好后点确定退出即可  
	然后我们双击证书，在详细信息里找到指纹，复制值备用
	这时我们证书就算添加好了
7. 配置证书
	1. PowerShell 管理员 （win7不支持）
		```PowerShell
		$thumbprint = "{SSL证书指纹}"
		$path = (Get-WmiObject -Namespace root\cimv2\TerminalServices -Class Win32_TSGeneralSetting -Filter 'TerminalName="RDP-Tcp"').__path
		Set-WmiInstance -Path $path -argument @{SSLCertificateSHA1Hash="$thumbprint"}

		```
	2. 使用WMIC(老系统普遍支持，新系统逐渐废弃)，打开cmd
		```PowerShell
		wmic /namespace:\\root\cimv2\TerminalServices PATH Win32_TSGeneralSetting Set SSLCertificateSHA1Hash="{SSL证书指纹}"
		```
	3. 修改注册表(前两者都不能用再用这个)
		```ini
		HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp
		```
		在此路径下新建一个`SSLCertificateSHA1Hash`的二进制值后双击在数值数据内填入SSL证书指纹，确定即可
