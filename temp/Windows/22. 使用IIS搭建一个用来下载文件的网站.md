3. 安装iis
	1. 步骤 1：启用 IIS 功能​
	
	2. ​**按 `Win + R`**，输入 `optionalfeatures` 打开 ​**Windows 功能**。
	3. 勾选以下选项：
	    - ​**Internet Information Services**​ → ​**Web 管理工具**​（全选）
	    - ​**万维网服务**​ → ​**静态内容**​（必需）  
	        （若需支持其他功能，可勾选 ​**目录浏览**、**HTTP 重定向**​ 等）
	4. 点击 ​**确定**，等待安装完成。
	
	5. 步骤 2：验证 IIS 是否运行s​
	
	6. 打开浏览器，访问 `http://localhost`。
	7. 若显示 ​**IIS 欢迎页面**，说明安装成功
4. 配置共享文件夹权限
	1. **创建共享文件夹**
	2. 
		1. 新建一个文件夹（如 `C:\FileServer`），放入需要提供下载的文件。
		2. ​**右键文件夹 → 属性 → 共享**​ → 点击 ​**共享...​**​ → 添加用户 `Everyone` 并赋予 ​**读取**​ 权限。
5. 打开IIS管理器创建站点
	1. - 右键 ​**站点**​ → ​**添加网站**。
	- 填写以下信息：
	    - ​**站点名称**​：`FileDownload`
	    - ​**物理路径**​：`C:\FileServer`（选择刚才的文件夹）
	    - ​**绑定类型**​：`http` 或 `https`（需证书）
	    - ​**IP 地址**​：`*`（所有可用 IP）
	    - ​**端口**​：`80`（HTTP）或 `443`（HTTPS）或者其他的
	- 点击 ​**确定**。
	1. 启用目录浏览
		1. 如果希望用户能看到文件列表：
		2. 在 IIS 中选中你的站点 → 双击 ​**目录浏览**。
		3. 点击右侧 ​**启用**。
6. ## **设置文件下载权限**​

### ​**步骤 1：配置匿名访问**​

1. 在 IIS 中选中站点 → 双击 ​**身份验证**。
2. 右键 ​**匿名身份验证**​ → ​**启用**。
3. 确保匿名用户身份为 ​**应用程序池标识**​（默认）。

### ​**步骤 2：设置 MIME 类型（避免文件无法下载）​**​

1. 在 IIS 中选中站点 → 双击 ​**MIME 类型**。
2. 添加常见文件类型的 MIME（如 `.apk`、`.dmg`）：
    - ​**扩展名**​：`.apk`  
        ​**MIME 类型**​：`application/vnd.android.package-archive`
    - ​**扩展名**​：`.dmg`  
        ​**MIME 类型**​：`application/x-apple-diskimage`

### ​**步骤 3：禁用执行权限（安全加固）​**​

1. 在 IIS 中选中站点 → 双击 ​**处理程序映射**。
2. 右键 ​**编辑功能权限**​ → 取消勾选 ​**脚本**​（仅保留 ​**读取**）


3. 遇到问题无法下载显示无权限的，可能是因为没有配置MIME类型导致不能下载该类型的文件
