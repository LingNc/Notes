问题 2：Win10 怎么把显示屏“直通”给它？

**概念纠正：**

你不能只直通“显示屏”，因为显示屏是插在显卡上的。

**你要做的操作叫：显卡直通 (GPU Passthrough)。**

也就是把那张 **RTX 1060** 连同它上面的 HDMI/DP 接口，全部送给 Win10。这时候你把显示器插在 RTX 1060 上，Win10 的画面就出来了。

这是一个大工程，请严格按步骤操作（这步做完，你的 PVE 控制台可能就不显示画面了，因为显卡被 Win10 抢走了，这是正常的）：

#### 第一步：开启 IOMMU (主板与内核)

1. **BIOS 设置：** 确保你之前已经开启了 `VT-d` (Intel) 或 `IOMMU` (AMD)。
    
2. **PVE 内核设置：**
    
    - 在 PVE Shell 输入：`nano /etc/default/grub`
        
    - 找到 `GRUB_CMDLINE_LINUX_DEFAULT="..."` 这一行。
        
    - 修改为（Intel CPU）：
        
        Plaintext
        
        ```
        GRUB_CMDLINE_LINUX_DEFAULT="quiet intel_iommu=on iommu=pt"
        ```
        
    - 保存退出 (`Ctrl+O`, `Ctrl+X`)。
        
    - **更新引导：** `update-grub`。
        

#### 第二步：屏蔽显卡驱动 (让 PVE 别碰显卡)

我们要把 NVIDIA 的驱动拉黑，不让 PVE 加载它，这样 Win10 才能抢走。

1. 编辑黑名单文件：
    
    Bash
    
    ```
    nano /etc/modprobe.d/pve-blacklist.conf
    ```
    
2. 添加以下内容：
    
    Plaintext
    
    ```
    blacklist nouveau
    blacklist nvidia
    blacklist nvidiafb
    ```
    
1. 保存退出。
    

#### 第三步：加载 VFIO 模块

1. 编辑模块文件：
    
    Bash
    
    ```
    nano /etc/modules
    ```
    
2. 添加以下内容：
    
    Plaintext
    
    ```
    vfio
    vfio_iommu_type1
    vfio_pci
    vfio_virqfd
    ```
    
1. 保存退出。
    
2. **这一步做完，必须重启 PVE 物理机！** (`reboot`)
    

#### 第四步：直通显卡给 Win10

重启回来后，开始配置虚拟机。

1. 点击 **Win10 (100)** -> **硬件 (Hardware)**。
    
2. **添加 PCI 设备：**
    
    - 点击 **Add** -> **PCI Device**。
        
    - **Device:** 在下拉列表里找到你的 **NVIDIA GeForce GTX 1060**。
        
    - **关键勾选：**
        
        - **All Functions:** **必须勾选** (这样会把显卡的视频部分和音频部分一起直通)。
            
        - **ROM-Bar:** 勾选。
            
        - **PCI-Express:** 勾选。
            
    - 点击 Add。
        
3. **修改显示输出 (Display):**
    
    - 现在你的 Hardware 列表里有显卡了。
        
    - 找到 **Display (显示)** 这一项，双击它。
        
    - 改为 **None (无)**。
        
    - _解释：既然你要用物理显示器了，就把 PVE 虚拟的那个网页监视器关掉，防止冲突。_
        

#### 第五步：接线与开机

1. **物理接线：** 把你的显示器 HDMI/DP 线，插到 **RTX 1060** 的接口上（千万别插主板上的核显口）。
    
2. **开机 Win10**。
    
3. **安装驱动：**
    
    - 这时候显示器可能还没亮，或者分辨率很低。你可能需要通过远程桌面 (RDP) 或者这时候暂时把 Display 改回 `Default` 来辅助操作（如果 Display 是 Default，物理显示器可能不亮）。
        
    - **最佳盲操方案：** 保持 Display 为 None。等几分钟，Win10 会自动联网更新驱动。或者你听到 Win10 启动声音后，屏幕闪烁几下，画面就应该出来了。
        
    - 如果画面出来了，去 NVIDIA 官网下载最新的驱动安装即可。
        

**警告：**

如果直通后开机报错（比如 `Code 43`），或者 PVE 彻底死机，说明 IOMMU 分组或者 VBIOS 有问题，那时候我们需要更高级的排错（先把上面的步骤做完告诉我结果）。
