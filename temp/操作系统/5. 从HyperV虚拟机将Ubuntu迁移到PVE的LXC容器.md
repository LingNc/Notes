4. 同上先备份rootfs然后妥善保管（对于无特权容器下如果要用docker必须排除backingFsBlockDev设备)
```bash
sudo tar --xattrs --numeric-owner \
--exclude='./proc/*' \
--exclude='./sys/*' \
--exclude='./dev/*' \
--exclude='./tmp/*' \
--exclude='./var/tmp/*' \
--exclude='./run/*' \
--exclude='./mnt/*' \
--exclude='./media/*' \
--exclude='./lost+found' \
--exclude='./var/lib/docker/volumes/backingFsBlockDev' \
-czpf /mnt/samba/rootfs-kubuntu.tar.gz -C /mnt/root .
```
5. 安装PVE操作系统，之后启动并上传上一次导出的tar.gz文件目录到 对应的local存储器的 template/cache 目录下然后在网页上选中对应的CT模板就可以看到刚刚放入的 tar.gz 文件。
6. 选择创建一个CT（LXC容器），因为这里使用的Ubuntu 22.04里面跑了docker等环境并且有snap使用非特权容器无法启动，需要使用特权容器，勾选存储磁盘的时候点击高级选择选项 discard其他根据需要自己分配。如图![](Pasted%20image%2020260321134452.png)

5. 然后需要对fstab的硬盘挂载全部删除，首先挂载lxc容器的根目录到本地（假设你的容器ID是100我这边是）：`pct mount 100`，然后编辑 ：nano /var/lib/lxc/100/rootfs/etc/fstab,如果有记录就全部注释即可。如图：![](Pasted%20image%2020260321135210.png)
然后取消挂载:pct unmount 100
6. 由于图形界面无法开启特权容器的嵌套虚拟化，需要手动开启：pct set 100 -features nesting=1
7. 启动容器发现几乎没有内存占用，CPU占用特别高：![](Pasted%20image%2020260321135419.png)
查看进程![](Pasted%20image%2020260321135517.png)
说明这个systemd卡死了应该在一直输出报错日志，查看日志：
```bash
Mar 21 13:25:35 ubuntu42 systemd[1]: Condition check resulted in ACPI event daemon being skipped.
............
```
全部是这个日志，停止并挂载容器：pct stop 100
pct mount 100，
屏蔽相关的服务：
ln -sf /dev/null /var/lib/lxc/100/rootfs/etc/systemd/system/acpid.service
ln -sf /dev/null /var/lib/lxc/100/rootfs/etc/systemd/system/acpid.socket
ln -sf /dev/null /var/lib/lxc/100/rootfs/etc/systemd/system/acpid.path
如果有其他问题可以屏蔽驱动服务
ln -sf /dev/null /var/lib/lxc/100/rootfs/etc/systemd/system/systemd-udevd.service
ln -sf /dev/null /var/lib/lxc/100/rootfs/etc/systemd/system/systemd-udev-trigger.service
如果带有桌面可以手动设置为从命令行启动不启动桌面
ln -sf /lib/systemd/system/multi-user.target /var/lib/lxc/100/rootfs/etc/systemd/system/default.target
取消挂载并启动
pct unmount 100
pct start 100
发现所有的服务均可以正常启动。
8. 可以使用xrdp进行登陆可以发现桌面等其他服务均可以正常使用。接下来可以直通显卡、电池等物理设备。
9. 显卡和电池：
```bash
pct stop 100
nano /etc/pve/lxc/100.conf
```
末尾添加
```conf
# --- GPU 显卡直通 ---
# 允许容器读写主设备号为 226（显卡）的所有设备
lxc.cgroup2.devices.allow: c 226:* rwm
# 把宿主机的 /dev/dri 目录直接挂载到容器的同样位置
lxc.mount.entry: /dev/dri dev/dri none bind,optional,create=dir

# --- 笔记本电池与电源直通 ---
# 把宿主机的电源状态目录映射进容器，使用 ro(只读) 保护物理机电源控制不被容器篡改
lxc.mount.entry: /sys/class/power_supply sys/class/power_supply none bind,ro,optional,create=dir

```
