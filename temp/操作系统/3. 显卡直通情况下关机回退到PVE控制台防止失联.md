3. 你的决定非常明智。面对黑屏“盲操”确实没有安全感，而且万一出了问题（比如网络断了），没有本地控制台不仅是麻烦，简直是灾难。

你需要的这个脚本在 PVE 圈子里被称为 **"Hook Script" (钩子脚本)**。

它的作用就像给虚拟机装了两个“开关”：

- **开机前 (pre-start)：** 自动踢掉 PVE 的显示服务，把显卡干干净净地交给 Win10。
    
- **关机后 (post-stop)：** 自动把 PVE 的显示服务拉回来，重新接管显卡，让屏幕重新亮起 PVE 的登录界面。
    

由于你之前已经按照我的教程**屏蔽了 NVIDIA 驱动 (Blacklist)**，我们现在只需要一个轻量级的脚本来处理 **EFI Framebuffer (帧缓冲)** 的解绑和重新绑定即可。这比那种需要动态加载 NVIDIA 驱动的脚本要安全得多，不容易炸。

请按以下步骤操作：

### 第一步：创建存放脚本的目录

PVE 有专门存放这类脚本的地方（Snippets）。打开 PVE 的 Shell，输入：

Bash

```
mkdir -p /var/lib/vz/snippets
```

### 第二步：编写脚本

我们需要创建一个 Perl 脚本（PVE 官方支持的语言）。

1. **新建文件：**
    
    Bash
    
    ```
    nano /var/lib/vz/snippets/gpu-hook.pl
    ```
    
2. **复制粘贴以下内容：**
    
    _(这个脚本会自动检测你的虚拟机启动和停止，并执行屏幕切换逻辑)_
    
    Perl
    
    ```
    #!/usr/bin/perl
    
    use strict;
    use warnings;
    
    print "GUEST HOOK: " . join(' ', @ARGV). "\n";
    
    # 获取参数: 虚拟机ID 和 阶段
    my $vmid = shift;
    my $phase = shift;
    
    if ($phase eq 'pre-start') {
        # --- 虚拟机启动前：让 PVE 闭眼 (释放显卡) ---
        print "Preparing GPU for Passthrough...\n";
    
        # 1. 停止 PVE 的控制台输出服务
        system("echo 0 > /sys/class/vtconsole/vtcon0/bind");
        system("echo 0 > /sys/class/vtconsole/vtcon1/bind");
    
        # 2. 踢掉 EFI 帧缓冲 (关键步骤，否则画面会卡住)
        system("echo efi-framebuffer.0 > /sys/bus/platform/drivers/efi-framebuffer/unbind");
    
        print "GPU released from Host.\n";
    
    } elsif ($phase eq 'post-stop') {
        # --- 虚拟机关机后：让 PVE 睁眼 (回收显卡) ---
        print "Re-attaching GPU to Host...\n";
    
        # 1. 重新绑定 EFI 帧缓冲
        system("echo efi-framebuffer.0 > /sys/bus/platform/drivers/efi-framebuffer/bind");
    
        # 2. 恢复 PVE 控制台输出
        system("echo 1 > /sys/class/vtconsole/vtcon0/bind");
        system("echo 1 > /sys/class/vtconsole/vtcon1/bind");
    
        print "Host console restored.\n";
    }
    
    exit(0);
    ```
    
1. **保存并退出：** 按 `Ctrl+O` 回车，然后 `Ctrl+X`。
    
2. **赋予执行权限：**
    
    Bash
    
    ```
    chmod +x /var/lib/vz/snippets/gpu-hook.pl
    ```
    

### 第三步：把脚本挂载到 Win10 虚拟机上

现在我们要告诉 PVE：启动 ID 为 100 的虚拟机时，去跑这个脚本。

1. 在 Shell 里输入：
    
    Bash
    
    ```
    qm set 100 --hookscript local:snippets/gpu-hook.pl
    ```
    
    _(注意：如果你的存储 ID 不叫 `local`，请根据实际情况修改，通常默认就是 `local`)_
    
2. **验证一下：**
    
    你可以查看虚拟机的配置文件 `cat /etc/pve/qemu-server/100.conf`，里面应该多了一行 `hookscript: ...`。
    

### 第四步：测试效果

1. **确保你面前的显示器插在 GTX 1060 上**。
    
2. 此时屏幕显示的应该是 PVE 的黑底白字控制台。
    
3. **启动 Win10：**
    
    - 点击 PVE 网页上的 Start。
        
    - **观察屏幕：** PVE 的画面应该会突然消失（黑屏一下），然后变成 Windows 的转圈圈画面。
        
4. **关闭 Win10：**
    
    - 在 Windows 里点关机。
        
    - **观察屏幕：** 屏幕黑掉，几秒钟后，PVE 的登录提示符（`pve login:`）应该会重新跳出来！
        

### ⚠️ 可能遇到的坑及应对

- **坑1：关机后屏幕亮了，但卡在最后一行不动。**
    
    - **解决：** 这是因为显示画面恢复了，但没有触发“重绘”。你只需要按一下键盘上的 **回车键**，登录提示符就会刷出来了。
        
- **坑2：关机后依然彻底黑屏，回车也没用。**
    
    - **原因：** 你的显卡可能进入了深度休眠，或者被 Windows 的驱动锁死了状态。
        
    - **解决：** 这种情况比较麻烦，需要更复杂的脚本来重置 PCI 设备（Load/Unload VFIO），但考虑到你还要用这台机器做别的事，建议先试用上面的简单版脚本。如果不行，我们再加码。
