2. 测试环境：winserver2022 ltsc， PVE 9.2 ，Debian12
3. 参考链接：
	1. [5. 从HyperV虚拟机将Ubuntu迁移到PVE的LXC容器](5.%20从HyperV虚拟机将Ubuntu迁移到PVE的LXC容器.md)
4. 先同前面一样备份rootfs的根文件系统获得tar.gz文件。
	如果已经使用vhdx转换到raw并且正常启动了，已经是vm磁盘了，可以通过kpartx进行挂载，挂载之后将对应的分区挂载到/mnt/root就可以和前面一样进行数据提取了。之后注意umount和kpartx -dv
	如果是需要docker的话有很多问题需要在外部排除:
	```bash
	sudo tar --xattrs --numeric-owner \
	--exclude='./proc/*' \
	--exclude='./sys/*' \
	--exclude='./dev/*' \
	--exclude='./tmp/*' \
	--exclude='./var/tmp/*' \
	--exclude='./run/*' \
	--exclude='./mnt/*' \
	--exclude='./media/*' \
	--exclude='./lost+found' \
	--exclude='./var/lib/docker/volumes/backingFsBlockDev' \
	-czpf /mnt/samba/rootfs-kubuntu.tar.gz -C /mnt/root .
	```
5. 如果是手动放置的话需要将对应的tar.gz的rootfs文件放在CT模板中（在local的/var/lib/vz/template/cache这个目录中）。
6. 然后创建虚拟机选择这个模板进行创建。
7. 挂载lxc(pct mount 103)然后删除fstab中的一些挂载盘的号，有记录就全部删掉：nano /var/lib/lxc/103/rootfs/etc/fstab，之后pct unmount 103
8. 如果需要tun设备（比如zerotier需要进行设备直通）
	```bash
	nano /etc/pve/lxc/103.conf
	# 最下面添加
	lxc.cgroup2.devices.allow: c 10:200 rwm
	lxc.mount.entry: /dev/net/tun dev/net/tun none bind,create=file
	```
