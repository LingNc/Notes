1. 通过api进行创建
	
	1. 发送 HTTP 请求到 _users 数据库，创建一个新文档。  
	2. 文档的 _id 必须以 org.couchdb.user: 前缀开头。
	
	示例（使用 curl 命令）：
	
	````bash
	curl -X POST http://localhost:5984/_users \
	  -H "Content-Type: application/json" \
	  -d '{
	    "_id": "org.couchdb.user:用户名",
	    "name": "用户名",
	    "roles": [],
	    "type": "user",
	    "password": "用户密码"
	  }'
	````
	
	请将 用户名 和 用户密码 替换为你需要的值。
	
	注意事项：
	
	- 需要管理员权限才能创建用户。
	- 用户信息会被 CouchDB 自动加密存储。
	
	如果你使用的是 CouchDB 3.x 及以上版本，建议通过 Fauxton（Web 管理界面）进行用户管理，路径为：  
	**_users** 数据库 → 新建文档。
2. 通过web界面进行创建
	1. 在浏览器中访问你的 CouchDB 地址，比如：  
	   ```
	   http://localhost:5984/_utils/
	   ```
	2. 登录管理员账号。
	3. 在左侧菜单中找到 **Databases**，点击进入。
	4. 找到并点击 **_users** 数据库。
	5. 点击右上角的 **Create Document**（新建文档）按钮。
	6. 在弹出的编辑器中，填写如下内容（注意字段名和格式）：
	
	   ```json
	   {
	     "_id": "org.couchdb.user:你的用户名",
	     "name": "你的用户名",
	     "roles": [],
	     "type": "user",
	     "password": "你的密码"
	   }
	   ```
	
	7. 填写完成后，点击 **Create Document** 或 **Save** 保存即可。
