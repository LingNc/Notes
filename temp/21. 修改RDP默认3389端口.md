1. ‎创建于2025‎年‎7‎月‎8‎日，测试环境：win10，win11
2. 设置新的端口号（例如3390）
```powershell
# 1. 设置新的端口号（例如3390）
$newPort = 3390

# 2. 修改远程桌面端口
Set-ItemProperty -Path "HKLM:\System\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" -Name "PortNumber" -Value $newPort

# 3. 重启远程桌面服务
Restart-Service -Name "TermService" -Force

# 4. 添加防火墙规则
New-NetFirewallRule -DisplayName "RDP-CustomPort" -Direction Inbound -LocalPort $newPort -Protocol TCP -Action Allow
```
2. 验证是否成功修改
	```powershell
	Get-ItemProperty -Path "HKLM:\System\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp" -Name "PortNumber"
	```
