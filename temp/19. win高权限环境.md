1. 在复制删除修改系统文化的时候，经常需要使用管理员权限，但是很多被操作的文件都是系统正在使用的文件，如果登录该用户或者系统正在使用的用户进行操作，可能会导致无法复制或删除文件。
2. 有几种操作方式可以避免这个问题：
    1. 使用 `Administrator` 用户登录 Windows 系统进行操作。
        - 这样可以确保操作系统的核心文件和用户文件不被占用。
        - 避免了用户文件夹中正在运行的应用程序对文件的锁定。
        - 如何启用 `Administrator` 用户：
            - 打开命令提示符（管理员），输入以下命令启用 `Administrator` 用户：
              ```cmd
              net user Administrator /active:yes
              ```
            - 然后注销当前用户，登录 `Administrator` 用户进行操作。
            - 如果不需要，可以在操作完成后禁用该用户：
              ```cmd
              net user Administrator /active:no
              ```
    2. 进入恢复选项的命令提示符操作。
       1. 进入设置 > 更新与安全 > 恢复 > 高级启动，点击“立即重启”。
       2. 在重启后选择“疑难解答” > “高级选项” > “命令提示符”。
    3. 使用`PE`微系统（如 Windows PE）进行操作。
