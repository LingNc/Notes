4. 配置内网机器上的转发 debian12
5.  Ai：prompt:`如何在debain12上做内网转发，把内网的192.168.1.6这个机器的ip的一个端口转发到debian12这个机器上9999端口，然后我可以通过debian12上面的端口来远程唤醒这个局域网内的机器，最后写一个直接完成操作的脚本实现这一项操作，脚本要求输入内网ip地址和端口（也可以不输入端口，默认9）和debian12需要开放的端口（转发到0.0.0.0上以便能够从外网访问），bash脚本自动化完成所有操作`
6. ans：
要在 Debian 12 上配置端口转发，将外部请求转发到内网 Windows 机器的 Wake-on-LAN（WOL）端口，您可以按照以下步骤进行操作：

**1. 确保内核启用了 IP 转发：**

首先，确认系统已启用 IP 转发功能。编辑 `/etc/sysctl.conf` 文件，确保以下行未被注释：

```ini
net.ipv4.ip_forward=1
```

然后，运行以下命令使更改生效：

```bash
sudo sysctl -p
```

**2. 安装并启用 nftables：**

Debian 12 默认使用 `nftables`，但如果未安装，您可以通过以下命令安装：

```bash
sudo apt-get update
sudo apt-get install nftables
```

安装完成后，启用并启动 `nftables` 服务：

```bash
sudo systemctl enable --now nftables
```

**3. 配置端口转发规则：**

编辑 `/etc/nftables.conf` 文件，添加以下规则：

```nft
#!/usr/sbin/nft -f
flush ruleset

table ip filter {
    chain input {
        type filter hook input priority 0; policy drop;
        iifname "lo" accept
        ct state established,related accept
        tcp dport 9999 accept
    }
}

table ip nat {
    chain prerouting {
        type nat hook prerouting priority -100; policy accept;
        tcp dport 9999 dnat to 192.168.1.6:9
    }
    chain postrouting {
        type nat hook postrouting priority 100; policy accept;
        oifname "lo" accept
        ip saddr 192.168.1.6 snat to 192.168.1.6
    }
}
```

请将 `192.168.1.6` 替换为您内网 Windows 机器的实际 IP 地址。

保存并退出编辑器后，加载配置：

```bash
sudo nft -f /etc/nftables.conf
```

**4. 编写自动化脚本：**

以下是一个 Bash 脚本示例，用于自动化上述配置过程：

```bash
#!/bin/bash

# 检查是否以 root 用户运行
if [ "$(id -u)" -ne 0 ]; then
    echo "请以 root 用户运行此脚本。"
    exit 1
fi

# 获取用户输入
read -p "请输入内网机器的 IP 地址（默认 192.168.1.6）: " internal_ip
internal_ip=${internal_ip:-192.168.1.6}

read -p "请输入内网机器的端口（默认 9）: " internal_port
internal_port=${internal_port:-9}

read -p "请输入 Debian 12 上需要开放的端口（默认 9999）: " external_port
external_port=${external_port:-9999}

# 安装 nftables
apt-get update
apt-get install -y nftables

# 启用 nftables 服务
systemctl enable --now nftables

# 启用内核转发
echo "net.ipv4.ip_forward=1" >> /etc/sysctl.conf
sysctl -p

# 配置 nftables 端口转发
cat > /etc/nftables.conf <<EOF
#!/usr/sbin/nft -f
flush ruleset

table ip filter {
    chain input {
        type filter hook input priority 0; policy drop;
        iifname "lo" accept
        ct state established,related accept
        tcp dport $external_port accept
    }
}

table ip nat {
    chain prerouting {
        type nat hook prerouting priority -100; policy accept;
        tcp dport $external_port dnat to $internal_ip:$internal_port
    }
    chain postrouting {
        type nat hook postrouting priority 100; policy accept;
        oifname "lo" accept
        ip saddr $internal_ip snat to $internal_ip
    }
}
EOF

# 加载 nftables 配置
nft -f /etc/nftables.conf

echo "配置完成。现在，您可以通过访问 Debian 12 上的端口 $external_port 来远程唤醒内网机器。"
```

将上述脚本保存为 `setup_wol.sh`，并赋予执行权限：

```bash
chmod +x setup_wol.sh
```

然后运行脚本：

```bash
sudo ./setup_wol.sh
```

运行脚本后，您可以通过访问 Debian 12 上的端口（默认为 9999）来远程唤醒内网 Windows 机器。

请注意，确保内网 Windows 机器的防火墙允许接收来自 Debian 12 的 WOL 数据包。
