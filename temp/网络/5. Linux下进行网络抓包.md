1. 安装tcpdump

如果系统未安装tcpdump，先通过包管理器安装：

```bash
# Debian/Ubuntu
sudo apt-get install tcpdump

# CentOS/RHEL
sudo yum install tcpdump
```

### 2. 确定网络接口

使用以下命令查看可用网络接口：

```bash
ip addr
# 或
ifconfig
```

常见的接口如`eth0`（以太网）、`wlan0`（无线）等。

### 3. 基础抓包命令

抓取所有经过指定接口的流量并保存：

```bash
sudo tcpdump -i <接口名> -s 0 -w 输出文件.pcap
```

- `-i`：指定接口（如`eth0`）。
- `-s 0`：抓取完整数据包（默认只抓前96字节）。
- `-w`：保存到文件（如`output.pcap`）。

​**示例**​：

```bash
sudo tcpdump -i eth0 -s 0 -w capture.pcap
```

按`Ctrl+C`停止抓包。

### 4. 添加过滤条件

仅捕获特定流量，例如HTTP（端口80）或指定IP：

```bash
sudo tcpdump -i eth0 'tcp port 80' -s 0 -w http.pcap
sudo tcpdump -i eth0 host 192.168.1.100 -s 0 -w filtered.pcap
```

- `host`：过滤IP地址。
- `port`：过滤端口。
- 使用单引号包裹复杂表达式。

### 5. 限制抓包数量或大小

- `-c 100`：抓100个包后停止。
- `-C 10`：每10MB轮换文件（需配合`-W`限制文件数）。

```bash
sudo tcpdump -i eth0 -c 100 -s 0 -w 100packets.pcap
```

### 6. 验证抓包文件

使用`tcpdump`读取或Wireshark分析：

```bash
tcpdump -r capture.pcap
wireshark capture.pcap
```

### 7. 后台抓包（可选）

使用`&`或`nohup`让抓包在后台运行：

```bash
sudo nohup tcpdump -i eth0 -s 0 -w background.pcap &
```

### 常见问题

- ​**权限不足**​：使用`sudo`或以root用户运行。
- ​**文件过大**​：添加过滤条件或限制大小。
- ​**选错接口**​：确认接口名称及活动状态。

### 总结命令示例

```bash
# 基本抓包
sudo tcpdump -i eth0 -s0 -w output.pcap

# 抓取HTTP流量
sudo tcpdump -i eth0 'tcp port 80' -s0 -w http.pcap

# 抓取特定IP的流量
sudo tcpdump -i eth0 host 192.168.1.5 -s0 -w ip_traffic.pcap
```

通过上述步骤，你可以高效地在Linux系统中进行网络抓包并保存为pcap文件，便于后续分析。
