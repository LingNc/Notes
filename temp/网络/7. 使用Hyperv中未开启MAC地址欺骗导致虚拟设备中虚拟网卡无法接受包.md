3. 测试环境： Win10 Hyperv Debian12
4. 解决方法：
	1. - 在Windows宿主机上，以**管理员身份**打开 **PowerShell**。
	- 执行以下命令（请将 `你的Debian虚拟机名字` 替换成你在Hyper-V里给它起的名字，比如 "Debian" 或者 "Debian12"）：
	    ```
	    Set-VMNetworkAdapter -VMName "你的Debian虚拟机名字" -MacAddressSpoofing On
	    ```
	    例如，如果你的虚拟机就叫 "Debian"，那么命令就是：
	    ```
	    Set-VMNetworkAdapter -VMName "Debian" -MacAddressSpoofing On
	    ```
