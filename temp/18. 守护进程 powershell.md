在 Windows 中使用 PowerShell 创建和管理服务非常高效，尤其适合需要自动化或批量操作的场景。以下是 ​**PowerShell 方法**的完整指南，涵盖创建、配置、调试和删除服务的详细步骤：

---

### ​**1. 创建新服务**​

使用 `New-Service` 命令，需以 ​**管理员身份运行 PowerShell**。

#### ​**基本语法**​

```powershell
New-Service -Name "服务名称" `
            -BinaryPathName "可执行文件路径" `
            -DisplayName "显示名称" `
            -StartupType <启动类型> `
            -Description "服务描述"
```

#### ​**参数说明**​

| 参数                | 必填  | 说明                                                            |
| ----------------- | --- | ------------------------------------------------------------- |
| `-Name`           | 是   | 服务名称（唯一标识，如 `MyAppService`）。                                  |
| `-BinaryPathName` | 是   | 程序绝对路径（如 `"C:\App\MyApp.exe"`）。若路径含空格，用双引号包裹。                 |
| `-DisplayName`    | 否   | 显示在服务管理器中的名称（如 `"My Application Service"`）。                   |
| `-StartupType`    | 否   | 启动类型：`Automatic`（自动）、`Manual`（手动）、`Disabled`（禁用）。默认 `Manual`。 |
| `-Description`    | 否   | 服务描述（如 `"后台运行 MyApp 的核心进程"`）。                                 |

#### ​**示例：创建自动启动的服务**​

```powershell
New-Service -Name "MyAppService" `
            -BinaryPathName "C:\MyApp\app.exe --arg1 value" `
            -DisplayName "My Application" `
            -StartupType Automatic `
            -Description "Runs MyApp in background."
```

---

### ​**2. 管理服务状态**​

#### ​**启动服务**​

```powershell
Start-Service -Name "MyAppService"
```

#### ​**停止服务**​

```powershell
Stop-Service -Name "MyAppService" -Force  # -Force 强制停止
```

#### ​**重启服务**​


```powershell
Restart-Service -Name "MyAppService"
```

#### ​**设置启动类型**​

```powershell
Set-Service -Name "MyAppService" -StartupType Automatic  # 自动
Set-Service -Name "MyAppService" -StartupType Manual      # 手动
Set-Service -Name "MyAppService" -StartupType Disabled    # 禁用
```

---

### ​**3. 查看服务信息**​

#### ​**获取服务状态**​

```powershell
Get-Service -Name "MyAppService"  # 状态包括 Running/Stopped
```

#### ​**查看所有服务**​

```powershell
Get-Service | Where-Object { $_.DisplayName -like "*MyApp*" }  # 按名称过滤
```

#### ​**查看服务详情（依赖项、PID 等）​**​

```powershell
Get-CimInstance -ClassName Win32_Service -Filter "Name='MyAppService'"
```

---

### ​**4. 修改服务属性**​

#### ​**更改可执行文件路径**​

```powershell
sc.exe config "MyAppService" binPath= "C:\NewPath\app.exe"
```

#### ​**修改服务描述**​

```powershell
sc.exe description "MyAppService" "New description text"
```

---

### ​**5. 删除服务**​

```powershell
Remove-Service -Name "MyAppService"  # PowerShell 5.0+
# 或使用 sc 命令
sc.exe delete "MyAppService"
```

### ​**6. 高级场景**​

#### ​**​(1) 运行批处理脚本（.bat/.cmd）​**​

通过 `cmd.exe` 调用脚本：

```powershell
New-Service -Name "BatService" `
            -BinaryPathName "C:\Windows\System32\cmd.exe /c C:\Scripts\run.bat" `
            -StartupType Automatic
```

#### ​**​(2) 运行 Python 脚本**​

指定 Python 解释器路径：

```powershell
New-Service -Name "PyService" `
            -BinaryPathName "C:\Python39\python.exe C:\Scripts\app.py" `
            -StartupType Automatic
```

#### ​**​(3) 依赖其他服务**​

使用 `-DependsOn` 指定依赖服务：

```powershell
New-Service -Name "MyAppService" `
            -BinaryPathName "C:\MyApp\app.exe" `
            -DependsOn "MySQL", "Redis"
```

### ​**7. 调试服务问题**​

#### ​**​(1) 查看服务日志**​


```powershell
# 查看事件日志中的服务错误
Get-EventLog -LogName Application -Source "MyAppService" -Newest 10
```

#### ​**​(2) 测试程序是否可执行**​

直接运行命令验证路径：

```powershell
& "C:\MyApp\app.exe" --arg1 value  # 确保无报错
```

#### ​**​(3) 常见错误**​

|错误|原因|解决方案|
|---|---|---|
|`Cannot start service MyAppService on computer '.'`|路径错误或权限不足|检查 `BinaryPathName` 是否正确，以管理员身份运行 PowerShell。|
|`The service did not respond to the start or control request`|程序未正确处理服务控制命令|确保程序支持作为服务运行（如监听 `SERVICE_CONTROL` 事件）。|
|`The specified service has been marked for deletion`|服务未完全停止|重启系统后重试删除。|

### ​**8. 完整示例：创建并管理服务**​


以下是基于 ​**`npc.exe`**​ 的完整 PowerShell 服务创建和管理教程，参数已调整为 `--server=xxxxxx.com:8025 -vkey=xxxxxxxxxxx -tls_enable=true`：

---

### ​**1. 创建 NPC 服务**​

以 ​**管理员身份运行 PowerShell**，执行以下命令创建服务：


```powershell
# 创建服务（开机自动启动）
New-Service -Name "NpcService" `
            -BinaryPathName "C:\path\to\npc.exe --server=xxxxxx.com:8025 -vkey=xxxxxxxxxxx -tls_enable=true" `
            -DisplayName "NPC Client Service" `
            -StartupType Automatic `
            -Description "NPC client for connecting to remote server."

# 启动服务
Start-Service -Name "NpcService"
```

#### ​**参数说明**​

|参数|值|说明|
|---|---|---|
|`--server`|`xxxxxx.com:8025`|NPC 服务器地址和端口|
|`-vkey`|`xxxxxxxxxxx`|客户端验证密钥（从服务端获取）|
|`-tls_enable`|`true`|启用 TLS 加密通信|

---

### ​**2. 验证服务状态**​

```powershell
# 查看服务是否运行
Get-Service -Name "NpcService"

# 查看服务详情（包括进程 PID）
Get-CimInstance -ClassName Win32_Service -Filter "Name='NpcService'"
```

#### ​**预期输出**​

```markdown

------   ----               -----------
Running  NpcService         NPC Client Service
```

#### ​**​(3) 常见错误与解决**​

|错误|原因|解决方案|
|---|---|---|
|`Cannot start service NpcService`|路径或参数错误|检查 `BinaryPathName` 路径和参数格式（避免空格需用双引号包裹）。|
|`Failed to connect to server`|服务器不可达或密钥错误|确认 `--server` 地址、端口及 `-vkey` 正确，检查防火墙规则。|

### ​**7. 完整示例脚本**​

将以下内容保存为 `create_npc_service.ps1`，以管理员身份运行：

```powershell
# 定义参数
$serviceName = "NpcService"
$npcPath = "C:\npc\npc.exe"  # 替换为你的 NPC 路径
$server = "xxxxxx.com:8025"  # 替换为你的服务器地址
$vkey = "xxxxxxxxxxx"        # 替换为你的客户端密钥

# 创建服务
New-Service -Name $serviceName `
            -BinaryPathName "$npcPath --server=$server -vkey=$vkey -tls_enable=true" `
            -DisplayName "NPC Client" `
            -StartupType Automatic `
            -Description "NPC client service."

# 启动服务
Start-Service -Name $serviceName

# 验证状态
Get-Service -Name $serviceName
```

---

### ​**注意事项**​

1. ​**路径规范**​：
    - 如果路径含空格（如 `C:\Program Files\npc.exe`），需用双引号包裹：
        
        ```powershell
        -BinaryPathName """C:\Program Files\npc.exe"" --server=..."
        ```
        
2. ​**TLS 证书**​：
    - 若需自定义 CA 证书，添加参数 `-tls_cert=C:\path\to\ca.crt`。
3. ​**后台运行**​：
    - 确保 `npc.exe` 支持以服务模式运行（无交互窗口）。
